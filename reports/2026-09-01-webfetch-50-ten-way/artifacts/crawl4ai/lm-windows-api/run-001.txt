The following is a list of the reference content for the Windows application programming interface (API) for desktop and server applications.
Using the Windows API, you can develop applications that run successfully on all versions of Windows while taking advantage of the features and capabilities unique to each version. (Note that this was formerly called the Win32 API. The name Windows API more accurately reflects its roots in 16-bit Windows and its support on 64-bit Windows.)
[](https://learn.microsoft.com/en-us/windows/win32/apiindex/windows-api-list#user-interface)

## Deprecated or legacy APIs
The following are technologies and APIs that are outdated or have been replaced or deprecated from the Windows client and server operating systems.
  * [DirectMusic](https://learn.microsoft.com/en-us/previous-versions/ms807133\(v=msdn.10\))
  * [DirectSound](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ee416975\(v=vs.85\))
  * [Microsoft UDDI SDK](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/aa966237\(v=bts.10\)) is now included with [Microsoft BizTalk Server](https://learn.microsoft.com/en-us/previous-versions/bb905520\(v=msdn.10\)).
  * [Network Dynamic Data Exchange (DDE)](https://learn.microsoft.com/en-us/windows/win32/ipc/network-dde-reference)
  * [Remote Installation Service](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-server-2003/cc786442\(v=ws.10\)): Use [Windows Deployment Services](https://learn.microsoft.com/en-us/windows/win32/wds/windows-deployment-services-portal) instead.
  * [Virtual Disk Service (VDS)](https://learn.microsoft.com/en-us/windows/win32/vds/vds-reference): Use [Windows Storage Management](https://learn.microsoft.com/en-us/windows-hardware/drivers/storage/windows-storage-management-api-portal) instead.
  * Terminal Services: Use [Remote Desktop Services](https://learn.microsoft.com/en-us/windows/win32/termserv/terminal-services-reference).
  * [Windows Media Rights Manager](https://learn.microsoft.com/en-us/previous-versions//bb614742\(v=vs.85\))
  * [Windows Messaging (MAPI)](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/windowsmapi/mapi-stub-library-and-simple-mapi): Use [Office MAPI](https://learn.microsoft.com/en-us/previous-versions/office/developer/office-2007/cc765775\(v=office.12\)) instead.
  * [Windows Gadget Platform](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/gadgetplatform/windows-gadget-platform-portal): Create UWP apps instead.
  * [Windows Sidebar](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/sidebar/-sidebar-ref-entry): Create UWP apps instead.
  * [Windows SideShow](https://learn.microsoft.com/en-us/previous-versions//ms744179\(v=vs.85\)): No replacement.
  * [WPF Bitmap Effects](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/wibe/-wibe-about-bitmapeffects)
