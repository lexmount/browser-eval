#### Body

application/json

- Option 1
- Option 2

Provide either `ids` or `urls`, but not both.

[​](#body-one-of-0-ids)

ids

string\[]

required

Document IDs obtained from searches.

Required array length: `1 - 100` element s

Required string length: `1 - 2048`

Example:

```

["https://arxiv.org/pdf/2307.06435"]


```

[​](#body-one-of-0-urls)

urls

string\[]

URLs to crawl (backwards compatible with the `ids` parameter).

Required array length: `1 - 100` element s

Required string length: `1 - 2048`

Example:

```

["https://arxiv.org/pdf/2307.06435"]


```

[​](#body-one-of-0-compliance-one-of-0)

compliance

enum\<string> | null

Enterprise-only compliance mode. Set to `hipaa` for HIPAA mode. Requires cache-only retrieval with supported parameters. See the HIPAA docs for details.

Available options:

`hipaa`

Example:

`"hipaa"`

[​](#body-one-of-0-text-one-of-0)

text

boolean Advanced text options · objectbooleanAdvanced text options · object

default:false

Text extraction options for each result.

[​](#body-one-of-0-highlights-one-of-0)

highlights

boolean Advanced highlights options · objectbooleanAdvanced highlights options · object

default:false

Text snippets the LLM identifies as most relevant from each page.

[​](#body-one-of-0-summary-one-of-0)

summary

object | null

Summary of the webpage.

Show child attributes

[​](#body-one-of-0-extras-one-of-0)

extras

object | null

Extra parameters to pass.

Show child attributes

[​](#body-one-of-0-context-one-of-0)

context

boolean objectbooleanobject

deprecated

Deprecated: Use highlights or text instead. Returns page contents as a combined context string.

Example:

`true`

[​](#body-one-of-0-livecrawl-one-of-0)

livecrawl

enum\<string> | null

deprecated

Deprecated: Use maxAgeHours instead for content freshness control. livecrawl does not guarantee freshly fetched parser output and may be served according to server freshness policy. Do not send livecrawl and maxAgeHours together.

Available options:

`never`,

`always`,

`fallback`,

`preferred`

Example:

`"preferred"`

[​](#body-one-of-0-livecrawl-timeout-one-of-0)

livecrawlTimeout

integer | null

default:10000

The timeout for livecrawling in milliseconds.

Required range: `0 < x <= 90000`

Example:

`1000`

[​](#body-one-of-0-max-age-hours-one-of-0)

maxAgeHours

integer | null

Maximum age of cached content in hours. Positive values use cached content if it is less than this many hours old; 0 fetches fresh content and is the supported way to apply text rendering options to newly fetched pages; -1 always uses cache; omitted uses fallback fetching when cached content is unavailable. Maximum supported value is 720 hours.

Required range: `-1 <= x <= 720`

Example:

`24`

[​](#body-one-of-0-subpages-one-of-0)

subpages

integer | null

default:0

The number of subpages to crawl. The actual number crawled may be limited by system constraints.

Required range: `0 <= x <= 100`

Example:

`1`

[​](#body-one-of-0-subpage-target-one-of-0)

subpageTarget

string string\[]stringstring\[]

Term to find specific subpages of search results. Can be a single string or an array of strings.

Required string length: `1 - 100`

Example:

`"sources"`
