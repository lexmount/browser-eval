# Windows API index - Win32 apps | Microsoft Learn

The following is a list of the reference content for the Windows application programming interface (API) for desktop and server applications.

Using the Windows API, you can develop applications that run successfully on all versions of Windows while taking advantage of the features and capabilities unique to each version. (Note that this was formerly called the Win32 API. The name Windows API more accurately reflects its roots in 16-bit Windows and its support on 64-bit Windows.)

## Deprecated or legacy APIs

The following are technologies and APIs that are outdated or have been replaced or deprecated from the Windows client and server operating systems.

- [DirectMusic](/en-us/previous-versions/ms807133%28v=msdn.10%29)
- [DirectSound](/en-us/previous-versions/windows/desktop/ee416975%28v=vs.85%29)
- [Microsoft UDDI SDK](/en-us/previous-versions/windows/desktop/aa966237%28v=bts.10%29) is now included with [Microsoft BizTalk Server](/en-us/previous-versions/bb905520%28v=msdn.10%29).
- [Network Dynamic Data Exchange (DDE)](../ipc/network-dde-reference)
- [Remote Installation Service](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc786442%28v=ws.10%29): Use [Windows Deployment Services](../wds/windows-deployment-services-portal) instead.
- [Virtual Disk Service (VDS)](../vds/vds-reference): Use [Windows Storage Management](/en-us/windows-hardware/drivers/storage/windows-storage-management-api-portal) instead.
- Terminal Services: Use [Remote Desktop Services](../termserv/terminal-services-reference).
- [Windows Media Rights Manager](/en-us/previous-versions//bb614742%28v=vs.85%29)
- [Windows Messaging (MAPI)](/en-us/previous-versions/windows/desktop/windowsmapi/mapi-stub-library-and-simple-mapi): Use [Office MAPI](/en-us/previous-versions/office/developer/office-2007/cc765775%28v=office.12%29) instead.
- [Windows Gadget Platform](/en-us/previous-versions/windows/desktop/gadgetplatform/windows-gadget-platform-portal): Create UWP apps instead.
- [Windows Sidebar](/en-us/previous-versions/windows/desktop/sidebar/-sidebar-ref-entry): Create UWP apps instead.
- [Windows SideShow](/en-us/previous-versions//ms744179%28v=vs.85%29): No replacement.
- [WPF Bitmap Effects](/en-us/previous-versions/windows/desktop/wibe/-wibe-about-bitmapeffects)
