业界基准如何影响本设计

WCXB：保留标注方法，不保留失效 URL

WCXB 的完整参考正文、必须出现片段和必须排除样板噪声很有价值；但 live URL 一旦失效或正文漂移就退出正式集合。本版只保留实际页面复核仍正确的旧案例。

WCXB 源仓库 →

LiveWeb-IE：采用标注原则

它强调 live URL、稳定事实、自然语言任务和人工验证。本项目采用“失效即替换、修改即升版并重跑”，但不引入其图片/链接/XPath Agent 任务，因为那超出通用 Web Fetch 正文契约。

LiveWeb-IE 论文 →

Readability / Dragnet：只作离线抽取参考

二者主要在固定 HTML 上评正文抽取；不能覆盖云服务的网络、重定向、JavaScript、限流和认证。因此不直接替代端到端 live URL 主榜。

失效案例：保留证据，不参与排名

登录墙、CAPTCHA、WAF、历史 4xx/5xx 和正文漂移仍保留在淘汰清单中用于追溯，但不混入主榜，避免把“正文抽取质量”变成“目标网站是否还活着”。
