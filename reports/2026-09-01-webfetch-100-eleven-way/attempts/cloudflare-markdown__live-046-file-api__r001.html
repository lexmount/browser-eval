## Concepts and Usage

The File API enables web applications to access files and their contents.

Web applications can access files when the user makes them available, either using a [file `<input>` element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/file) or [via drag and drop](https://developer.mozilla.org/en-US/docs/Web/API/DataTransfer/files).

Sets of files made available in this way are represented as [`FileList`](https://developer.mozilla.org/en-US/docs/Web/API/FileList) objects, which enable a web application to retrieve individual [`File`](https://developer.mozilla.org/en-US/docs/Web/API/File) objects. In turn [`File`](https://developer.mozilla.org/en-US/docs/Web/API/File) objects provide access to metadata such as the file's name, size, type, and last modified date.

[`File`](https://developer.mozilla.org/en-US/docs/Web/API/File) objects can be passed to [`FileReader`](https://developer.mozilla.org/en-US/docs/Web/API/FileReader) objects to access the contents of the file. The [`FileReader`](https://developer.mozilla.org/en-US/docs/Web/API/FileReader) interface is asynchronous, but a synchronous version, available only in [web workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API), is provided by the [`FileReaderSync`](https://developer.mozilla.org/en-US/docs/Web/API/FileReaderSync) interface.

## Relationship to other file-related APIs

There are two other major APIs that also deal with files: [File and Directory Entries API](https://developer.mozilla.org/en-US/docs/Web/API/File_and_Directory_Entries_API) and [File System API](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API).

The File API is the most basic one. It supports reading and processing file data explicitly provided by the user in the form of a form element input or drag-and-drop operation. It also enables binary data handling via blobs.

The File and Directory Entries API, like the File API, also deals with files provided by the user via form inputs or drag-and-drop operations. However, instead of a single file, the input element now allows the selection of a directory or multiple files. The API then provides a way to process the directory or files. It is mostly Chrome's own invention—you will find that its extensions to other interfaces are all prefixed with `webkit`. The [File and Directory Entries API](https://developer.mozilla.org/en-US/docs/Web/API/File_and_Directory_Entries_API#history) has a more complete story about its implementation and standardization. It was originally intended to support a full virtual file system, but now only supports read operations on user-provided data.

The File System API provides a virtual file system for web applications, so that they can persistently store data in a virtual system which is private to the document's origin (known as an [Origin private file system (OPFS)](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API/Origin_private_file_system)). The File System Access API further extends the File System API to allow websites to read and write user files, subject to user consent. Unlike the File API and the File and Directory Entries API, the File System API is purely JavaScript and does not deal with form inputs.

## Interfaces

[<code>Blob</code>](https://developer.mozilla.org/en-US/docs/Web/API/Blob)

Represents a "Binary Large Object", meaning a file-like object of immutable, raw data; a [<code>Blob</code>](https://developer.mozilla.org/en-US/docs/Web/API/Blob) can be read as text or binary data, or converted into a [<code>ReadableStream</code>](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) so its methods can be used for processing the data.



[<code>File</code>](https://developer.mozilla.org/en-US/docs/Web/API/File)

Provides information about a file and allows JavaScript in a web page to access its content.



[<code>FileList</code>](https://developer.mozilla.org/en-US/docs/Web/API/FileList)

Returned by the <code>files</code> property of the HTML [<code>&lt;input&gt;</code>](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input) element; this lets you access the list of files selected with the <code>&lt;input type="file"&gt;</code> element. It's also used for a list of files dropped into web content when using the drag and drop API; see the [<code>DataTransfer</code>](https://developer.mozilla.org/en-US/docs/Web/API/DataTransfer) object for details on this usage.



[<code>FileReader</code>](https://developer.mozilla.org/en-US/docs/Web/API/FileReader)

Enables web applications to asynchronously read the contents of files (or raw data buffers) stored on the user's computer, using [<code>File</code>](https://developer.mozilla.org/en-US/docs/Web/API/File) or [<code>Blob</code>](https://developer.mozilla.org/en-US/docs/Web/API/Blob) objects to specify the file or data to read.



[<code>FileReaderSync</code>](https://developer.mozilla.org/en-US/docs/Web/API/FileReaderSync)

Enables web applications to synchronously read the contents of files (or raw data buffers) stored on the user's computer, using [<code>File</code>](https://developer.mozilla.org/en-US/docs/Web/API/File) or [<code>Blob</code>](https://developer.mozilla.org/en-US/docs/Web/API/Blob) objects to specify the file or data to read.



### Extensions to other interfaces

[<code>URL.createObjectURL()</code>](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static%20%22URL.createObjectURL()")

Creates a URL that can be used to fetch a [<code>File</code>](https://developer.mozilla.org/en-US/docs/Web/API/File) or [<code>Blob</code>](https://developer.mozilla.org/en-US/docs/Web/API/Blob) object.



[<code>URL.revokeObjectURL()</code>](https://developer.mozilla.org/en-US/docs/Web/API/URL/revokeObjectURL_static%20%22URL.revokeObjectURL()")

Releases an existing object URL which was previously created by calling [<code>URL.createObjectURL()</code>](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static%20%22URL.createObjectURL()").
