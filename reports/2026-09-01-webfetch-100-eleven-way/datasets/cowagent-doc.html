完整题目

读取 CowAgent 的 Web Fetch 工具文档。输出应说明工具名称、URL 输入，以及该工具用于获取网页内容或网页正文。

参考答案

Web Fetch（web_fetch）用于根据 URL 获取网页内容。调用时传入目标网页 URL，工具返回可供 Agent 使用的网页正文。
