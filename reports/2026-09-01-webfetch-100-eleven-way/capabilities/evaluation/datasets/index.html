覆盖的关键边界

JavaScript 渲染

页面初始 HTML 只有外壳，正文由脚本插入。只返回导航文字不算成功。

跨站页面模板

文章、论坛、商品、集合、列表、文档和服务页来自不同域名，检查正文完整性与样板噪声。

HTTP 重定向

服务端先返回 3xx 与 Location，客户端应自动访问目标并返回最终正文；不是只返回一个链接。

标注协议

文档按正文事实判断；图片和视频不以乱码或二进制转字符串为成功，必须检查资源 URL/元数据或可校验的原始字节。
