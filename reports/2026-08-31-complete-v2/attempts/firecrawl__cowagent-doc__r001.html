| 参数 | 类型 | 必填 | 说明 |

| Word | `.docx` |
| 文本 | `.txt`、`.md`、`.csv`、`.log` |
| 表格 | `.xls`、`.xlsx` |
| 演示文稿 | `.ppt`、`.pptx` |

## [​](https://docs.cowagent.ai/zh/tools/web-fetch\#%E4%BD%BF%E7%94%A8%E5%9C%BA%E6%99%AF)  使用场景

- 获取网页的文本内容
- 下载并解析远程文档
- 获取 API 响应内容

`web_fetch` 只能获取静态 HTML 内容。如果页面需要 JavaScript 渲染（如 SPA 单页应用），请使用 `browser` 工具。
