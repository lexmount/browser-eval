业界基准如何影响本设计

WCXB：直接采用

2,008 页、1,613 个域名、七种结构类型，标准答案包含完整正文、必须出现片段和必须排除的样板噪声。本轮按类型各取 4 条，共 28 条，并固定到具体提交。

WCXB 源仓库 →

LiveWeb-IE：采用标注原则

它强调 live URL、稳定事实、自然语言任务和人工验证。本项目采用“页面漂移单独判定”，但不引入其图片/链接/XPath Agent 任务，因为那超出通用 Web Fetch 正文契约。

LiveWeb-IE 论文 →

Readability / Dragnet：只作离线抽取参考

二者主要在固定 HTML 上评正文抽取；不能覆盖云服务的网络、重定向、JavaScript、PDF、限流和认证。因此不直接替代端到端 live URL 主榜。

长尾失败集：单独分榜

登录墙、CAPTCHA、WAF 和历史 4xx/5xx 很有诊断价值，但目标和合规边界不同。混入主榜会把“正文抽取质量”变成“反爬成功率”，结论不可解释。
