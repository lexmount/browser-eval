固定指标契约

评测指标定义

指标在运行前固定。HTTP 成功不等于正文成功；主榜速度也不会纳入快速返回空壳、错误页或不完整正文的调用。

transport_success

供应商完成请求，并将响应判为请求成功；它不代表正文正确。

content_pass

机器内容初判：显著标记、最小长度、全部事实组和反向错误标记四道确定性规则均通过。

marker_recall

命中的显著标记数除以该案例登记的显著标记总数。

elapsed_ms

客户端墙钟耗时，包含网络与供应商处理时间。

deadline_overrun

实际墙钟耗时超过配置的 timeout；socket timeout 不被假定为严格截止时间。

content_chars

持久化供应商输出的 Unicode 字符数。

markdown_headings

输出中的 Markdown 标题行数量。

markdown_links

输出中目标为 HTTP(S) 的 Markdown 链接数量。

html_tags

输出中残留的类 HTML 标签数量。

fact_coverage

命中的预登记事实组除以全部必需事实组；同组可接受表达等价。

forbidden_hits

输出中出现的预登记错误页、挑战页或拒绝访问文本。

content_sha256

完整输出的 SHA-256，用于核验报告预览与原始结果一致。

unique_line_ratio

去重后的非空规范化行数除以全部非空行数，用于诊断重复模板。

聚合规则

主榜 P50/P95：只统计请求成功且机器内容初判通过的有效调用。另在 summary.json 保留 transport_p50_ms/transport_p95_ms 与全部调用 P95，供网络和超时诊断；机器内容初判通过率的分母包含所有调用。
