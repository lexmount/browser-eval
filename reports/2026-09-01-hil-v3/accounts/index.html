账号准备

账号注册与凭据清单

按能力类别列出官方注册入口、API key 获取位置和需要填写的环境变量。报告不保存实际凭据。

当前主评测：Lexmount Global、Firecrawl、Tavily Extract、Exa Contents 与 Cloudflare /markdown。/content 不再作为参评方法；搜索 API 与模型绑定工具使用独立数据集。
提供方官方入口环境变量取得方式免费/准入说明
Lexmount Global
A · 核心评测 · 适配器已实现		注册 / 登录
获取凭据		LEXMOUNT_API_KEY
LEXMOUNT_PROJECT_ID		登录后打开 Settings → API Keys，创建或复制 API key，并复制对应 Project ID；本评测使用 api.lexmount.com。内测准入；API key 与 Project ID 必须来自同一个 Global 项目。
Firecrawl
A · 核心评测 · 适配器已实现		注册 / 登录
获取凭据		FIRECRAWL_API_KEY注册账号，打开 Firecrawl 控制台 API Keys 页面，创建以 fc- 开头的 key。存在无 key 的限流层；可复现评测应使用免费账号。
Tavily Extract
B · 已知 URL 抽取 · 适配器已实现		注册 / 登录
获取凭据		TAVILY_API_KEY注册或登录 Tavily Platform，从控制台复制 API key。官方快速开始说明每月有 1,000 免费 API credits，无需绑卡。
Exa Contents
B · 已知 URL 抽取 · 适配器已实现		注册 / 登录
获取凭据		EXA_API_KEY注册或登录 Exa 控制台，打开 API Keys，创建 key；如系统要求则设置预算。需要控制台账号；用量由 credits/预算控制。
Browserbase Fetch
B · 已知 URL 抓取候选 · 适配器待实现		注册 / 登录
获取凭据		BROWSERBASE_API_KEY
BROWSERBASE_PROJECT_ID		注册后创建或选择项目，从 Overview 控制台复制 API key 与 Project ID。官方页面存在契约冲突；打分前必须先以账号内实际接口核验。
Cloudflare Browser Rendering /markdown
B · 已知 URL 抽取 · 适配器已实现		注册 / 登录
获取凭据		CLOUDFLARE_API_TOKEN
CLOUDFLARE_ACCOUNT_ID		注册 Cloudflare，复制 32 位 Account ID，再创建自定义 API token：Account → Browser Rendering → Edit；运行前用 GET /client/v4/user/tokens/verify 验证。Workers Free 可用 Browser Rendering；token 需要 Browser Rendering Edit 权限，并受账户限额约束。
Bocha Web Search
D · 查询到搜索结果 · 适配器待实现		注册 / 登录
获取凭据		BOCHA_API_KEY在博查开放平台注册，在控制台创建 API key，并填入 BOCHA_API_KEY。搜索/摘要产品，不是任意已知 URL 抽取；应使用独立查询数据集。
Baidu Qianfan AI Search
D · 查询到搜索结果 · 适配器待实现		注册 / 登录
获取凭据		QIANFAN_API_KEY注册并完成百度智能云认证，打开千帆 API Key 管理并创建或复制 key。Web Search 按查询返回摘要、URL 与片段，不是任意 URL 抓取 API。
Tencent Cloud Web Search API
D · 查询到搜索结果 · 适配器待实现		注册 / 登录
获取凭据		TENCENT_WSA_API_KEY注册并完成认证，开通 Web Search API，再在控制台创建服务 API key。返回标题、片段与来源 URL 的搜索 API，应与已知 URL 抽取分开评测。
Alibaba Cloud Model Studio web_search + web_extractor
E · 模型绑定检索 · 适配器待实现		注册 / 登录
获取凭据		DASHSCOPE_API_KEY注册并完成阿里云认证，开通百炼 Model Studio，在 API Key 管理创建 key。web_extractor 当前随 web_search 出现在模型响应中；模型 token 与工具调用都计入成本。
Google Gemini URL Context
E · 模型绑定检索 · 适配器待实现		注册 / 登录
获取凭据		GEMINI_API_KEY登录 Google AI Studio，创建 API key 并填入 GEMINI_API_KEY。模型把检索到的 URL 内容作为输入 token，返回答案/引用，而不是独立原始 Markdown。
Bright Data Web Unlocker
C · 解锁场景数据集 · 适配器待实现		注册 / 登录
获取凭据		BRIGHTDATA_API_TOKEN
BRIGHTDATA_UNLOCKER_ZONE		注册账号，创建 Web Unlocker zone，再复制 API token 与 zone 名称。需要账号、计费或试用资格，以及 Web Unlocker zone。
ScrapingBee
C · 抓取 API 对比 · 适配器待实现		注册 / 登录
获取凭据		SCRAPINGBEE_API_KEY注册后打开 Account → API Key，复制 key。受试用/账户限额约束；生产套餐有月度最低消费。
Zyte API
C · 抓取 API 对比 · 适配器待实现		注册 / 登录
获取凭据		ZYTE_API_KEY注册后在控制台打开 Zyte API，创建或复制 API key。官方文档说明首月有 5 美元初始 credit。
ZenRows
C · 抓取 API 对比 · 适配器待实现		注册 / 登录
获取凭据		ZENROWS_API_KEY注册并复制控制台或 request builder 中显示的 API key。受账号/试用限额约束。
Scrapfly
C · 抓取 API 对比 · 适配器待实现		注册 / 登录
获取凭据		SCRAPFLY_API_KEY注册后打开控制台，复制项目 API key。受账号/试用限额约束。
Oxylabs Web Scraper API
C · 抓取 API 对比 · 适配器待实现		注册 / 登录
获取凭据		OXYLABS_USERNAME
OXYLABS_PASSWORD		注册或申请试用，开通 Web Scraper API 并复制用户凭据。所选产品可能需要试用或销售审批。
