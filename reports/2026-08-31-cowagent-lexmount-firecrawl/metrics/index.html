评测指标定义

指标在运行前固定定义。报告不会用 HTTP 成功替代正文成功，也不会从失败样本中删除慢请求。

transport_success

Provider completed the request and classified it as successful.

content_pass

At least one pre-registered content marker was present in the returned content.

marker_recall

Matched markers divided by all markers registered for the case.

elapsed_ms

Client wall-clock duration, including network and provider processing.

deadline_overrun

Elapsed wall-clock time exceeded the configured timeout value; socket timeouts are not assumed to be hard deadlines.

content_chars

Unicode character count of the persisted provider output.

markdown_headings

Number of Markdown heading lines in the output.

markdown_links

Number of Markdown links with HTTP(S) targets.

html_tags

Number of HTML-like tags remaining in the output.

聚合规则

P50/P95 仅在 transport success 样本上计算；all-attempts P95 同时保留，用于暴露超时和慢失败。Content pass 的分母包含所有 attempts。
