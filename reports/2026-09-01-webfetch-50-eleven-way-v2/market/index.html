国内供给结论：在本轮核验范围内，Lexmount 是已确认可直接按 URL 返回正文并完成实测的国内供应商。博查、百度、腾讯主要公开的是 Web Search；阿里和 Google 的相关能力偏模型工具或 URL Context，输入输出与独立 Web Fetch API 不同，所以不塞进供应商主表。
Lexmount 地域说明：本轮只调用 Global 的 api.lexmount.com。文档同时出现中国区域 API/控制台只能证明存在两套区域入口，不能据此断言底层只有两个物理服务节点。
