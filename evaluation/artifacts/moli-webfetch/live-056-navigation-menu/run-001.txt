[Deno](https://deno.com)([/ˈdiːnoʊ/](https://ipa-reader.com/?text=%CB%88di%CB%90no%CA%8A), pronounced`dee-no`) is a JavaScript, TypeScript, and WebAssembly runtime with secure defaults and a great developer experience. It's built on[V8](https://v8.dev/),[Rust](https://www.rust-lang.org/), and[Tokio](https://tokio.rs/).

Learn more about the Deno runtime[in the documentation](https://docs.deno.com/runtime/manual).

## Installation

[#installation](#installation)

Install the Deno runtime on your system using one of the commands below. Note that there are a number of ways to install Deno - a comprehensive list of installation options can be found[here](https://docs.deno.com/runtime/manual/getting_started/installation).

Shell (Mac, Linux):

```text
curl -fsSL https://deno.land/install.sh | sh
```

PowerShell (Windows):

```text
irm https://deno.land/install.ps1 | iex
```

[Homebrew](https://formulae.brew.sh/formula/deno)(Mac):

```text
brew install deno
```

[Chocolatey](https://community.chocolatey.org/packages/deno)(Windows):

```text
choco install deno
```

[WinGet](https://winstall.app/apps/DenoLand.Deno)(Windows):

```text
winget install --id=DenoLand.Deno
```

[Scoop](https://scoop.sh/#/apps?q=deno&id=678d8fb557b611df996989c675b1099630a5bbee)(Windows):

```text
scoop install main/deno
```

## Your first Deno program

[#your-first-deno-program](#your-first-deno-program)

Deno can be used for many different applications, but is most commonly used to build web servers. Create a file called`server.ts`and include the following TypeScript code:

```text
Deno.serve((_req: Request) => {
  return new Response("Hello, world!");
});
```

Run your server with the following command:

```text
deno run --allow-net server.ts
```

This should start a local web server on[http://localhost:8000](http://localhost:8000).

Learn more about writing and running Deno programs[in the docs](https://docs.deno.com/runtime/manual).
