# Five-browser Web Fetch evidence

Canonical cohort: 150 unchanged tasks × five browsers = 750 selected calls.
All exact-body reference lifecycles are verified. Dynamic and other invariant
tasks retain their declared stable contracts rather than live-ranking snapshots.

Twenty additional calls replaced four complete five-browser cohorts after
reference-certification failures. Selection is based on reference validity,
not provider scores. `selection-audit.json` identifies the replaced cohorts;
`diagnostics/replaced-cases/` retains their original calls and failed certificates.

Raw local artifacts are immutable measurement evidence. Public packaging
redacts detected Google API-key-shaped strings in supplemental third-party
HTML only and records separate original/published hashes. Scored outputs,
task rules and persisted scores are not rewritten. Raw local HTML must not be
pushed or uploaded as a substitute for the reviewed publication projection.
