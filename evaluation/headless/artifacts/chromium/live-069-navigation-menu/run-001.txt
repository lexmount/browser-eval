## Intro

Prettier is an opinionated code formatter. It enforces a consistent style by parsing
your code and re-printing it with its own rules that take the maximum line length
into account, wrapping code when necessary.


### Input

```foo(reallyLongArg(), omgSoManyParameters(), IShouldRefactorThis(), isThereSeriouslyAnotherOne());```

                              


### Output

```foo(  reallyLongArg(),  omgSoManyParameters(),  IShouldRefactorThis(),
isThereSeriouslyAnotherOne(),);```


Prettier can be run [in your editor](https://github.githubassets.com/assets/j05-dce4d588268f0f7e.js "route-pattern") on-save, in a [pre-commit hook](https://github.githubassets.com/assets/runtime-helpers-f3f5d71440009c48.js "route-pattern"), or in [CI environments](https://github.githubassets.com/assets/runtime-helpers-f3f5d71440009c48.js "route-pattern") to ensure your codebase has a consistent style without devs ever having to post a nit-picky comment on a code review ever again!
