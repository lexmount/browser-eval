# `http` — HTTP modules[¶](#module-http "Link to this heading")

**Source code:** [Lib/http/__init__.py](https://github.com/python/cpython/tree/3.14/Lib/http/__init__.py)

---

`http` is a package that collects several modules for working with theHyperText Transfer
Protocol:

- [`http.client`](http.client.html#module-http.client "http.client: HTTP and HTTPS protocol client (requires sockets).") is a low-level HTTP protocol client; for high-level URLopening use [`urllib.request`](urllib.request.html#module-urllib.request "urllib.request: Extensible library for opening URLs.")
- [`http.server`](http.server.html#module-http.server "http.server: HTTP server and request handlers.") contains basic HTTP server classes based on [`socketserver`](socketserver.html#module-socketserver "socketserver: A framework for network servers.")
- [`http.cookies`](http.cookies.html#module-http.cookies "http.cookies: Support for HTTP state management (cookies).") has utilities for implementing state management with cookies
- [`http.cookiejar`](http.cookiejar.html#module-http.cookiejar "http.cookiejar: Classes for automatic handling of HTTP cookies.") provides persistence of cookies

The `http` module also defines the following enums that help you work with http related
code:
*class *http.HTTPStatus[¶](#http.HTTPStatus "Link to this definition")


Added in version 3.5.

A subclass of [`enum.IntEnum`](enum.html#enum.IntEnum "enum.IntEnum") that defines a set of HTTP status codes,reason phrases and long descriptions written in English.

Usage:

Copy

```>>> from http import HTTPStatus>>> HTTPStatus.OKHTTPStatus.OK>>> 
HTTPStatus.OK == 200True>>> HTTPStatus.OK.value200>>>
HTTPStatus.OK.phrase'OK'>>> HTTPStatus.OK.description'Request fulfilled, 
document follows'>>> list(HTTPStatus)[HTTPStatus.CONTINUE, HTTPStatus.SWITCHING_PROTOCOLS, 
...]```
