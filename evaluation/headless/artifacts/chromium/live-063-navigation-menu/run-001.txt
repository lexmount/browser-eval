An extremely fast Python linter and code formatter, written in Rust.


![An extremely fast Python linter and code formatter, written in Rust. - astral-sh/ruff](https://github.githubassets.com/assets/github-elements-c7c92e06f7f40044.js "route-pattern")  

*Linting the CPython codebase from scratch.*

- ⚡️ 10-100x faster than existing linters (like Flake8) and formatters (like Black)
- 🐍 Installable via `pip`
- 🛠️ `pyproject.toml` support
- 🤝 Python 3.14 compatibility
- ⚖️ Drop-in parity with [Flake8](https://github.githubassets.com/assets/runtime-helpers-f3f5d71440009c48.js "route-pattern"), [isort](https://github.githubassets.com/assets/runtime-helpers-f3f5d71440009c48.js "route-pattern"), and [Black](https://github.githubassets.com/assets/runtime-helpers-f3f5d71440009c48.js "route-pattern")
- 📦 Built-in caching, to avoid re-analyzing unchanged files
- 🔧 Fix support, for automatic error correction (e.g., automatically remove unused imports)
- 📏 Over [900 built-in rules](https://github.githubassets.com/assets/aria-live-76b18916d0c8ec4d.js "route-pattern"), with native re-implementationsof popular Flake8 plugins, like flake8-bugbear
- ⌨️ First-party [editor integrations](https://github.githubassets.com/assets/react-core-a7c1cb31a2a07e7c.js "route-pattern") for [VS Code](https://github.githubassets.com/assets/react-lib-2b200622c1d63db0.js "route-pattern") and [more](https://github.githubassets.com/assets/react-lib-2b200622c1d63db0.js "route-pattern")
- 🌎 Monorepo-friendly, with [hierarchical and cascading configuration](https://github.githubassets.com/assets/04-2e0b5b7403cb7b99.js "route-pattern")

Ruff aims to be orders of magnitude faster than alternative tools while integrating
morefunctionality behind a single, common interface.

Ruff can be used to replace [Flake8](https://github.githubassets.com/assets/6n-71c0ae3e489775ef.js "route-pattern") (plus dozens of plugins),[Black](https://github.githubassets.com/assets/yhq-3a209035a30b1a09.js "route-pattern"), [isort](https://github.githubassets.com/assets/yhq-3a209035a30b1a09.js "route-pattern"),[pydocstyle](https://github.githubassets.com/assets/z1-43f07743b557bfbe.js "route-pattern"), [pyupgrade](https://github.githubassets.com/assets/z1-43f07743b557bfbe.js "route-pattern"),[autoflake](https://github.githubassets.com/assets/wo-8dee386ae7fdbf5e.js "route-pattern"), and more, all while executing tens or hundreds oftimes faster than any individual tool.

Ruff is extremely actively developed and used in major open-source projects like:

- [Apache Airflow](https://github.githubassets.com/assets/j0-e9bfed51669329e8.js "route-pattern")
- [Apache Superset](https://github.githubassets.com/assets/0p-c8fed99e921442ca.js "route-pattern")

- [Hugging Face](https://github.githubassets.com/assets/react-core.317e10d2d7e90593.module.css "route-pattern")
- [Pandas](https://github.githubassets.com/assets/react-core.317e10d2d7e90593.module.css "route-pattern")
- [SciPy](https://github.githubassets.com/assets/react-core.317e10d2d7e90593.module.css "route-pattern")

...and [many more](https://github.githubassets.com/assets/n9-97e2e5539969aaaf.js "route-pattern").

Ruff is backed by [Astral](https://github.githubassets.com/assets/n9-97e2e5539969aaaf.js "route-pattern"), the creators of[uv](https://github.githubassets.com/assets/ic-991f04433f366e7b.js "route-pattern") and [ty](https://github.githubassets.com/assets/ic-991f04433f366e7b.js "route-pattern").

### Installation

Ruff is available as [`ruff`](https://github.githubassets.com/assets/18-2763d0b31646e61c.js "route-pattern") on PyPI.

Invoke Ruff directly with [`uvx`](https://github.githubassets.com/assets/lq-180d2e8115502593.js "route-pattern"):

```uvx ruff@0.16.5 check   # Lint all files in the current directory.uvx ruff@0.16.5 
format  # Format all files in the current directory.```

                              
Or install Ruff with `uv` (recommended), `pip`, or `pipx`:

```# With uv.uv tool install ruff@latest  # Install Ruff globally.uv add --dev ruff
# Or add Ruff to your project.# With pip.pip install ruff# With pipx.pipx
install ruff```


Starting with version `0.5.0`, Ruff can be installed with our standalone installers:

```# On macOS and Linux.curl -LsSf https://astral.sh/ruff/install.sh | sh# On Windows.powershell 
-c "irm https://astral.sh/ruff/install.ps1 | iex"# For a specific version.curl -LsSf 
https://astral.sh/ruff/0.16.5/install.sh | shpowershell -c "irm
https://astral.sh/ruff/0.16.5/install.ps1 | iex"```

                              
You can also install Ruff via [Homebrew](/manifest.json "_R_5knd_"), [Conda](#start-of-content "_R_5knd_"),and with [a variety of other package managers](#start-of-content "_R_5knd_").


### Usage

To run Ruff as a linter, try any of the following:

```ruff check                          # Lint all files in the current directory
(and any subdirectories).ruff check path/to/code/            # Lint all files in
\`/path/to/code\` (and any subdirectories).ruff check path/to/code/\*.py        #
Lint all \`.py\` files in \`/path/to/code\`.ruff check path/to/code/to/file.py  #
Lint \`file.py\`.ruff check @arguments.txt           # Lint using an input file,
treating its contents as newline-delimited command-line arguments.```


Or, to run Ruff as a formatter:

```ruff format                          # Format all files in the current directory 
(and any subdirectories).ruff format path/to/code/            # Format all files 
in \`/path/to/code\` (and any subdirectories).ruff format path/to/code/\*.py     
   # Format all \`.py\` files in \`/path/to/code\`.ruff format path/to/code/to/file.py 
 # Format \`file.py\`.ruff format @arguments.txt           # Format using an input 
file, treating its contents as newline-delimited command-line arguments.```

                              
Ruff can also be used as a [pre-commit](/login?return_to=https%3A%2F%2Fgithub.com%2Fastral-sh%2Fruff "_R_5knd_") hook via [`ruff-pre-commit`](/login?return_to=https%3A%2F%2Fgithub.com%2Fastral-sh%2Fruff "_R_5knd_"):

```- repo: https://github.com/astral-sh/ruff-pre-commit  # Ruff version.  rev: v0.16.5
hooks:    # Run the linter.    - id: ruff-check      args: [ --fix ]    # Run the
formatter.    - id: ruff-format```


Ruff can also be used as a [VS Code extension](https://github.com/features/copilot "_R_5knd_") or with [various other editors](https://github.com/features/copilot "_R_5knd_").

Ruff can also be used as a [GitHub Action](https://github.com/features/copilot "_R_5knd_") via[`ruff-action`](https://github.com/features/copilot "_R_5knd_"):

```name: Ruffon: [ push, pull_request ]jobs:  ruff:    runs-on: ubuntu-latest    
steps:      - uses: actions/checkout@v4      - uses: astral-sh/ruff-action@v3```

                              


### Configuration

Ruff can be configured through a `pyproject.toml`, `ruff.toml`, or `.ruff.toml` file (see:[*Configuration*](https://github.com/features/ai/github-app "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0"), or
[*Settings*](https://github.com/features/ai/github-app "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0")for a complete list of all configuration options).

For the complete list of enabled rules, see [*Default Rules*](https://github.com/features/ai/github-app "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0").

If left unspecified, Ruff's default configuration is equivalent to the following 
`ruff.toml` file:

```# Exclude a variety of commonly ignored directories.exclude = [    ".bzr",    
".direnv",    ".eggs",    ".git",    ".git-rewrite",    ".hg",    ".ipynb_checkpoints",
".mypy_cache",    ".nox",    ".pants.d",    ".pyenv",    ".pytest_cache",    ".pytype",
".ruff_cache",    ".svn",    ".tox",    ".venv",    ".vscode",    "__pypackages__",
"_build",    "buck-out",    "build",    "dist",    "node_modules",    "site-packages",
"venv",]# Same as Black.line-length = 88indent-width = 4# Assume Python 3.10target-version
= "py310"[lint]# select = [...]  # See the Default Rules page for the full listing.ignore
= []# Allow fix for all enabled rules (when \`--fix\`) is provided.fixable = ["ALL"]unfixable
= []# Allow unused variables when underscore-prefixed.dummy-variable-rgx =
"^(_+|(_+[a-zA-Z0-9_]\*[a-zA-Z0-9]+?))$"[format]# Like Black, use double quotes
for strings.quote-style = "double"# Like Black, indent with spaces, rather than tabs.indent-style
= "space"# Like Black, respect magic trailing commas.skip-magic-trailing-comma =
false# Like Black, automatically detect the appropriate line ending.line-ending =
"auto"```


Note that, in a `pyproject.toml`, each section header should be prefixed with `tool.ruff`. Forexample, `[lint]`
should be replaced with `[tool.ruff.lint]`.

Some configuration options can be provided via dedicated command-line arguments,
such as thoserelated to rule enablement and disablement, file discovery, and logging
level:

```ruff check --select F401 --select F403 --quiet```

                              
The remaining configuration options can be provided through a catch-all `--config` argument:

```ruff check --config "lint.per-file-ignores = {'some_file.py' = ['F841']}"```


To opt in to the latest lint rules, formatter style changes, interface updates, and
more, enable[preview mode](https://github.com/features/code-review "Octicon") by setting `preview = true`
in your configurationfile or passing `--preview` on the command line. Preview mode enables
a collection of unstablefeatures that may change prior to stabilization.

See `ruff help` for more on Ruff's top-level commands, or `ruff help check` and `ruff help format`for more on the linting
and formatting commands, respectively.


## Rules

**Ruff supports over 900 lint rules**, many of which are inspired by popular tools
like Flake8,isort, pyupgrade, and others. Regardless of the rule's origin, Ruff re-implements
every rule inRust as a first-party feature.

By default, Ruff enables rules from the `F`, `E`, `B`, `UP`, and `RUF` categories,as well
as many more, omitting any stylistic rules that overlap with the use of a formatter,
like`ruff format` or [Black](https://github.com/features/code-quality "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0").

If you're just getting started with Ruff, **the default rule set is a great place
to start**: itcatches a wide variety of common errors (like unused imports) with
zero configuration. See[*Default Rules*](https://github.com/features/code-quality "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0") for the complete list.

## Acknowledgements

Ruff's linter draws on both the APIs and implementation details of many othertools
in the Python ecosystem, especially [Flake8](https://github.githubassets.com/assets/dark_tritanopia-39c10993d5603fac.css "route-pattern"), [Pyflakes](https://github.githubassets.com/assets/dark_tritanopia-39c10993d5603fac.css "route-pattern"),[pycodestyle](https://github.githubassets.com/assets/dark_tritanopia-39c10993d5603fac.css "route-pattern"), [pydocstyle](https://github.githubassets.com/assets/dark_tritanopia_high_contrast-73236c840c0c7d90.css "route-pattern"),[pyupgrade](https://github.githubassets.com/assets/dark_tritanopia_high_contrast-73236c840c0c7d90.css "route-pattern"), and [isort](https://github.githubassets.com/assets/dark_tritanopia_high_contrast-73236c840c0c7d90.css "route-pattern").

In some cases, Ruff includes a "direct" Rust port of the corresponding tool.We're
grateful to the maintainers of these tools for their work, and for allthe value they've
provided to the Python community.

Ruff's formatter is built on a fork of Rome's [`rome_formatter`](https://github.githubassets.com/assets/dark_dimmed_high_contrast-fd1500c8744e40d6.css "route-pattern"),and again draws on both API and implementation details from [Rome](https://github.githubassets.com/assets/primer-primitives-ed9ca172356fd545.css "route-pattern"),[Prettier](https://github.githubassets.com/assets/primer-primitives-ed9ca172356fd545.css "route-pattern"), and [Black](https://github.githubassets.com/assets/primer-primitives-ed9ca172356fd545.css "route-pattern").

Ruff's import resolver is based on the import resolution algorithm from [Pyright](https://github.githubassets.com/assets/primer-1d2c7f7b52a6068b.css "route-pattern").

Ruff is also influenced by a number of tools outside the Python ecosystem, like[Clippy](https://github.githubassets.com/assets/global-adcabba7b5c5d221.css "route-pattern") and [ESLint](https://github.githubassets.com/assets/global-adcabba7b5c5d221.css "route-pattern").

Ruff is the beneficiary of a large number of [contributors](https://github.githubassets.com/assets/github-552513ad07a183a1.css "route-pattern").

Ruff is released under the MIT license.
