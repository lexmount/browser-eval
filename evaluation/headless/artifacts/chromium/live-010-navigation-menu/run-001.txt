[Scrapy](https://github.githubassets.com/assets/rwf-1dd6dffd391bcb85.js "route-pattern") is a web scraping framework to extract structured data from websites.It is cross-platform, and requires Python 3.10+. It is maintained by [Zyte](https://github.githubassets.com/assets/tr-12064c91dfbbd248.js "route-pattern")(formerly Scrapinghub) and [many other contributors](https://github.githubassets.com/assets/tr-12064c91dfbbd248.js "route-pattern").

Install with:

```pip install scrapy```

                              
And follow the [documentation](https://github.githubassets.com/assets/20x-bcd86191b33f8bc4.js "route-pattern") to learn how to use it.

If you wish to contribute, see [Contributing](https://github.githubassets.com/assets/dsj-c0e1b19322545aa7.js "route-pattern").
