## Intro

Prettier is an opinionated code formatter. It enforces a consistent style by parsing
your code and re-printing it with its own rules that take the maximum line length
into account, wrapping code when necessary.


### Input

```foo(reallyLongArg(), omgSoManyParameters(), IShouldRefactorThis(), isThereSeriouslyAnotherOne());```

                              


### Output

```foo(  reallyLongArg(),  omgSoManyParameters(),  IShouldRefactorThis(),
isThereSeriouslyAnotherOne(),);```


Prettier can be run [in your editor](https://github.githubassets.com/assets/primer-react-css.5781bf31392a2ea2.module.css "route-pattern") on-save, in a [pre-commit hook](https://github.githubassets.com/assets/notifications-subscriptions-menu.d00501e0b1e31fd8.module.css "route-pattern"), or in [CI environments](https://github.githubassets.com/assets/notifications-subscriptions-menu.d00501e0b1e31fd8.module.css "route-pattern") to ensure your codebase has a consistent style without devs ever having to post a nit-picky comment on a code review ever again!
