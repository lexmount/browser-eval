## What is it?

**pandas** is a Python package that provides fast, flexible, and expressive datastructures
designed to make working with "relational" or "labeled" data botheasy and intuitive.
It aims to be the fundamental high-level building block fordoing practical, **real-world**
data analysis in Python. Additionally, it hasthe broader goal of becoming **the most
powerful and flexible open-source dataanalysis/manipulation tool available in any
language**. It is already well onits way towards this goal.

## Main Features

Here are just a few of the things that pandas does well:

- Easy handling of [**missing data**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") (represented as`NaN`, `NA`, or `NaT`) in floating point as well as non-floating point data
- Size mutability: columns can be [**inserted anddeleted**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") from DataFrame and higher dimensionalobjects
- Automatic and explicit [**data alignment**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern"): objects canbe explicitly aligned to a set of labels, or the user can simplyignore the labels and let `Series`, `DataFrame`, etc. automaticallyalign the data for you in computations
- Powerful, flexible [**group by**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") functionality to performsplit-apply-combine operations on data sets, for both aggregatingand transforming data
- Make it [**easy to convert**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") ragged,differently-indexed data in other Python and NumPy data structuresinto DataFrame objects
- Intelligent label-based [**slicing**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern"), [**fancyindexing**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern"), and [**subsetting**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") oflarge data sets
- Intuitive [**merging**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") and [**joining**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") datasets
- Flexible [**reshaping**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") and [**pivoting**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") ofdata sets
- [**Hierarchical**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") labeling of axes (possible to have multiplelabels per tick)
- Robust I/O tools for loading data from [**flat files**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern")(CSV and delimited), [**Excel files**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern"), [**databases**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern"),and saving/loading data from the ultrafast [**HDF5 format**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern")
- [**Time series**](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern")-specific functionality: date rangegeneration and frequency conversion, moving window statistics,date shifting and lagging


## Where to get it

The source code is currently hosted on GitHub at:[https://github.com/pandas-dev/pandas](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern")

Binary installers for the latest released version are available at the [PythonPackage Index (PyPI)](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern") and on [Conda](https://github.githubassets.com/assets/app-foundation-d65636f1d3602c9e.js "route-pattern").

```# condaconda install -c conda-forge pandas```

                              

```# or PyPIpip install pandas```


The list of changes to pandas between each release can be found[here](https://github.githubassets.com/assets/react-lib-2b200622c1d63db0.js "route-pattern"). For fulldetails, see the commit logs at [https://github.com/pandas-dev/pandas](https://github.githubassets.com/assets/04-2e0b5b7403cb7b99.js "route-pattern").

## Installation from sources

To install pandas from source you need [Cython](https://github.githubassets.com/assets/fe-68c3c54c382c22e7.js "route-pattern") in addition to the normaldependencies above. Cython can be installed from PyPI:

```pip install cython```

                              
In the `pandas` directory (same one where you found this file aftercloning the git repo), 
execute:

```pip install .```


or for installing in [development mode](https://github.githubassets.com/assets/dsj-c0e1b19322545aa7.js "route-pattern"):

```python -m pip install -ve . --no-build-isolation --config-settings editable-verbose=true```

                              
See the full instructions for [installing from source](https://github.githubassets.com/assets/primer-react-css.5781bf31392a2ea2.module.css "route-pattern").

There are also frequent [community meetings](https://github.githubassets.com/assets/pinned-octocat-093da3e6fa40.svg "_R_5knd_") for project maintainers open to the community as well as monthly [new contributor meetings](https://github.githubassets.com/assets/pinned-octocat-093da3e6fa40.svg "_R_5knd_") to help support new contributors.
