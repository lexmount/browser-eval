# `http` — HTTP modules[¶](#module-http "Link to this heading")

**Source code:** [Lib/http/__init__.py](https://github.com/python/cpython/tree/3.14/Lib/http/__init__.py)

---

`http` is a package that collects several modules for working with theHyperText Transfer
Protocol:

- [`http.client`](http.client.html#module-http.client "http.client: HTTP and HTTPS protocol client (requires sockets).") is a low-level HTTP protocol client; for high-level URLopening use [`urllib.request`](../_static/pygments.css?v=b86133f3 "http — HTTP modules")
- [`http.server`](../_static/pygments.css?v=b86133f3 "viewport") contains basic HTTP server classes based on [`socketserver`](../_static/pygments.css?v=b86133f3 "viewport")
- [`http.cookies`](../_static/pygments.css?v=b86133f3 "viewport") has utilities for implementing state management with cookies
- [`http.cookiejar`](../_static/pygments.css?v=b86133f3 "viewport") provides persistence of cookies

The `http` module also defines the following enums that help you work with http related
code:
*class *http.HTTPStatus[¶](../_static/classic.css?v=234b1a7c "highlight-")


Added in version 3.5.

A subclass of [`enum.IntEnum`](../_static/classic.css?v=234b1a7c "highlight-") that defines a set of HTTP status codes,reason phrases and long descriptions written in English.

Usage:

Copy

```>>> from http import HTTPStatus>>> HTTPStatus.OKHTTPStatus.OK>>> 
HTTPStatus.OK == 200True>>> HTTPStatus.OK.value200>>>
HTTPStatus.OK.phrase'OK'>>> HTTPStatus.OK.description'Request fulfilled, 
document follows'>>> list(HTTPStatus)[HTTPStatus.CONTINUE, HTTPStatus.SWITCHING_PROTOCOLS, 
...]```

[`http.client`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") module in the form of constants. The enum name isequal to the constant name (i.e. `http.HTTPStatus.OK` 
is also available as`http.client.OK`).


Changed in version 3.7: Added `421 MISDIRECTED_REQUEST` status code.


Added in version 3.8: Added `451 UNAVAILABLE_FOR_LEGAL_REASONS` status code.


Added in version 3.9: Added `103 EARLY_HINTS`, `418 IM_A_TEAPOT` and `425 TOO_EARLY` status codes.


Changed in version 3.13: Implemented RFC9110 naming for status constants. Old constant 
names are preserved forbackwards compatibility: `413 REQUEST_ENTITY_TOO_LARGE`, `414 REQUEST_URI_TOO_LONG`,`416 REQUESTED_RANGE_NOT_SATISFIABLE` and `422 UNPROCESSABLE_ENTITY`.
