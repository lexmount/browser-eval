# `csv` — CSV File Reading and Writing[¶](#module-csv "Link to this heading")

**Source code:** [Lib/csv.py](https://github.com/python/cpython/tree/3.14/Lib/csv.py)

---

The so-called CSV (Comma Separated Values) format is the most common import andexport
format for spreadsheets and databases.  CSV format was used for manyyears prior to
attempts to describe the format in a standardized way in[**RFC 4180**](https://datatracker.ietf.org/doc/html/rfc4180.html).  The lack of a well-defined standard means that subtle differencesoften exist in the data produced and consumed by different applications.  Thesedifferences can make it annoying to process CSV files from multiple sources.Still, while the delimiters and quoting characters vary, the overall format issimilar enough that it is possible to write a single module which canefficiently manipulate such data, hiding the details of reading and writing thedata from the programmer.

The `csv` module implements classes to read and write tabular data in CSVformat.  It
allows programmers to say, “write this data in the format preferredby Excel,”
or “read data from this file which was generated by Excel,” withoutknowing the
precise details of the CSV format used by Excel.  Programmers canalso describe the
CSV formats understood by other applications or define theirown special-purpose CSV
formats.

The `csv` module’s [`reader`](../_static/pygments.css?v=b86133f3 "viewport") and [`writer`](../_static/pygments.css?v=b86133f3 "viewport") objects read andwrite sequences.  Programmers can also read and write data in dictionary formusing the [`DictReader`](../_static/pygments.css?v=b86133f3 "highlight-") and [`DictWriter`](../_static/classic.css?v=234b1a7c "highlight-") classes.


See also
[**PEP 305**](../_static/classic.css?v=234b1a7c "highlight-") - CSV File API
The Python Enhancement Proposal which proposed this addition to Python.

## Module Contents[¶](../_static/classic.css?v=234b1a7c "highlight-")

The `csv` module defines the following functions:
csv.reader(*csvfile*, */*, *dialect='excel'*, *\*\*fmtparams*)[¶](../_static/classic.css?v=234b1a7c "highlight-")
Return a [reader object](../_static/classic.css?v=234b1a7c "highlight-") that will processlines from the given
*csvfile*.  A csvfile must be an iterable ofstrings, each in the reader’s defined
csv format.A csvfile is most commonly a file-like object or list.If *csvfile* is
a file object,it should be opened with `newline=''`. [[1]](../_static/classic.css?v=234b1a7c "highlight-")  An
optional*dialect* parameter can be given which is used to define a set of parametersspecific
to a particular CSV dialect.  It may be an instance of a subclass ofthe [`Dialect`](../_static/classic.css?v=234b1a7c "highlight-") class or one of the strings returned by the[`list_dialects()`](../_static/classic.css?v=234b1a7c "highlight-") function.  The other optional
*fmtparams* keyword argumentscan be given to override individual formatting parameters
in the currentdialect.  For full details about the dialect and formatting parameters,
seesection [Dialects and Formatting Parameters](../_static/classic.css?v=234b1a7c "highlight-").

Each row read from the csv file is returned as a list of strings.  Noautomatic data
type conversion is performed unless the [`QUOTE_NONNUMERIC`](../_static/classic.css?v=234b1a7c "highlight-") formatoption is specified (in which case unquoted fields are transformed into floats).

A short usage example:

Copy

```>>> import csv>>> with open('eggs.csv', newline='') as csvfile:... 
    spamreader = csv.reader(csvfile, delimiter=' ', quotechar='|')...     for row 
in spamreader:...         print(', '.join(row))Spam, Spam, Spam, Spam, Spam, Baked 
BeansSpam, Lovely Spam, Wonderful Spam```

where `eggs.csv` contains:

```Spam Spam Spam Spam Spam |Baked Beans|Spam |Lovely Spam| |Wonderful Spam|```
csv.writer(*csvfile*, */*, *dialect='excel'*, *\*\*fmtparams*)[¶](../_static/pydoctheme.css?v=4365c8fe "highlight-")
Return a writer object responsible for converting the user’s data into delimitedstrings
on the given file-like object.  *csvfile* can be any object with a[`write()`](../_static/pydoctheme.css?v=4365c8fe "highlight-") method.  If
*csvfile* is a file object, it should be opened with`newline=''` [[1]](../_static/pydoctheme.css?v=4365c8fe "highlight-").  An optional
*dialect*parameter can be given which is used to define a set of parameters specific
to aparticular CSV dialect.  It may be an instance of a subclass of the[`Dialect`](../_static/pydoctheme.css?v=4365c8fe "highlight-") class or one of the strings returned by the[`list_dialects()`](../_static/pydoctheme.css?v=4365c8fe "highlight-") function.  The other optional
*fmtparams* keyword argumentscan be given to override individual formatting parameters
in the currentdialect.  For full details about dialects and formatting parameters,
seethe [Dialects and Formatting Parameters](../_static/pydoctheme.css?v=4365c8fe "highlight-") section. To make itas easy as possible to interface with modules which implement the DB API, thevalue [`None`](../_static/pydoctheme.css?v=4365c8fe "highlight-") is written as the empty string.  While this isn’t areversible transformation, it makes it easier to dump SQL NULL data values toCSV files without preprocessing the data returned from a `cursor.fetch*`
call.All other non-string data are stringified with [`str()`](../_static/pydoctheme.css?v=4365c8fe "highlight-") before being written.

A short usage example:

Copy

```import csvwith open('eggs.csv', 'w', newline='') as csvfile:    spamwriter = csv.writer(csvfile, 
delimiter=' ',                            quotechar='|', quoting=csv.QUOTE_MINIMAL) 
   spamwriter.writerow(['Spam'] \* 5 + ['Baked Beans'])    spamwriter.writerow(['Spam', 
'Lovely Spam', 'Wonderful Spam'])```

which writes `eggs.csv` containing:

```Spam Spam Spam Spam Spam |Baked Beans|Spam |Lovely Spam| |Wonderful Spam|```

The `csv` module defines the following classes:
*class *csv.DictReader(*f*, *fieldnames=None*, *restkey=None*, *restval=None*, *dialect='excel'*,
*\*args*, *\*\*kwds*)[¶](../_static/pydoctheme.css?v=4365c8fe "stylesheet")
Create an object that operates like a regular reader but maps theinformation in each
row to a [`dict`](../_static/pydoctheme.css?v=4365c8fe "stylesheet") whose keys are given by theoptional
*fieldnames* parameter.

The *fieldnames* parameter is a [sequence](../_static/pydoctheme.css?v=4365c8fe "stylesheet").  If
*fieldnames* isomitted, the values in the first row of file *f* will be used as
thefieldnames and will be omitted from the results. If*fieldnames* is provided, they
will be used and the first row will beincluded in the results.  Regardless of how
the fieldnames are determined,the dictionary preserves their original ordering.

If a row has more fields than fieldnames, the remaining data is put in alist and
stored with the fieldname specified by *restkey* (which defaultsto `None`).  If a non-blank
row has fewer fields than fieldnames, themissing values are filled-in with the value
of *restval* (which defaultsto `None`).

All other optional or keyword arguments are passed to the underlying[`reader`](../_static/pydoctheme.css?v=4365c8fe "stylesheet") instance.

If the argument passed to *fieldnames* is an iterator, it will be coerced to a [`list`](../_static/pydoctheme.css?v=4365c8fe "stylesheet").


Changed in version 3.6: Returned rows are now of type `OrderedDict`.


Changed in version 3.8: Returned rows are now of type [`dict`](../_static/pydoctheme.css?v=4365c8fe "stylesheet").

A short usage example:

Copy

```>>> import csv>>> with open('names.csv', newline='') as csvfile:... 
    reader = csv.DictReader(csvfile)...     for row in reader:...         print(row['first_name'], 
row['last_name'])...Eric IdleJohn Cleese>>> print(row){'first_name': 'John', 
'last_name': 'Cleese'}```

where `names.csv` contains:

```first_name,last_nameEric,IdleJohn,Cleese```
*class *csv.DictWriter(*f*, *fieldnames*, *restval=''*, *extrasaction='raise'*, *dialect='excel'*,
*\*args*, *\*\*kwds*)[¶](../_static/pydoctheme.css?v=4365c8fe "stylesheet")
Create an object which operates like a regular writer but maps dictionariesonto output
rows.  The *fieldnames* parameter is a [`sequence`](../_static/pydoctheme.css?v=4365c8fe "stylesheet") of keys that identify the order in which values in thedictionary passed to the [`writerow()`](../_static/pydoctheme.css?v=4365c8fe "Search within Python 3.14.7 documentation") method are written to
file*f*.  The optional *restval* parameter specifies the value to bewritten if the
dictionary is missing a key in *fieldnames*.  If thedictionary passed to the `writerow()` method
contains a key not found in*fieldnames*, the optional *extrasaction* parameter indicates
what action totake.If it is set to `'raise'`, the default value, a [`ValueError`]( "Search within Python 3.14.7 documentation")is raised.If it is set to
`'ignore'`, extra values in the dictionary are ignored.Any other optional or keyword
arguments are passed to the underlying[`writer`]( "Search within Python 3.14.7 documentation") instance.

Note that unlike the [`DictReader`]( "Search within Python 3.14.7 documentation") class, the *fieldnames*
parameterof the `DictWriter` class is not optional.

If the argument passed to *fieldnames* is an iterator, it will be coerced to a [`list`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation").

A short usage example:

Copy

```import csvwith open('names.csv', 'w', newline='') as csvfile:    fieldnames = 
['first_name', 'last_name']    writer = csv.DictWriter(csvfile, fieldnames=fieldnames) 
   writer.writeheader()    writer.writerow({'first_name': 'Baked', 'last_name': 'Beans'}) 
   writer.writerow({'first_name': 'Lovely', 'last_name': 'Spam'})    writer.writerow({'first_name': 
'Wonderful', 'last_name': 'Spam'})```

which writes `names.csv` containing:

```first_name,last_nameBaked,BeansLovely,SpamWonderful,Spam```
*class *csv.Dialect[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
The `Dialect` class is a container class whose attributes containinformation for how to
handle doublequotes, whitespace, delimiters, etc.Due to the lack of a strict CSV
specification, different applicationsproduce subtly different CSV data.  `Dialect` instances
define how[`reader`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") and [`writer`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") instances behave.

All available `Dialect` names are returned by [`list_dialects()`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation"),and they can be registered with specific [`reader`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") and [`writer`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")classes through their initializer
(`__init__`) functions like this:

Copy

```import csvwith open('students.csv', 'w', newline='') as csvfile:    writer = csv.writer(csvfile, 
dialect='unix')```
*class *csv.excel[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
The `excel` class defines the usual properties of an Excel-generated CSVfile.  It is registered 
with the dialect name `'excel'`.
*class *csv.excel_tab[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
The `excel_tab` class defines the usual properties of an Excel-generatedTAB-delimited file. 
 It is registered with the dialect name `'excel-tab'`.
*class *csv.unix_dialect[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
The `unix_dialect` class defines the usual properties of a CSV filegenerated on UNIX systems, 
i.e. using `'\n'` as line terminator and quotingall fields.  It is registered with the 
dialect name `'unix'`.


Added in version 3.2.
*class *csv.Sniffer[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
The `Sniffer` class is used to deduce the format of a CSV file.

The `Sniffer` class provides two methods:
sniff(*sample*, *delimiters=None*)[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
Analyze the given *sample* and return a [`Dialect`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") subclassreflecting the parameters found.  If the optional
*delimiters* parameteris given, it is interpreted as a string containing possible 
validdelimiter characters.

If several delimiters fit the sample equally well —for example if both `','` and `';'` 
split every row consistently —the delimiters listed in the [`preferred`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") attributeare preferred, in that order,no matter how many times each of them occurs.
has_header(*sample*)[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
Analyze the sample text (presumed to be in CSV format) and return[`True`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") if the first row appears to be a series of column headers.Inspecting each column, one of two key criteria will be considered toestimate if the sample contains a header:

- the second through n-th rows contain numeric values
- the second through n-th rows contain strings where at least one value’slength differs from that of the putative header of that column.

Twenty-one rows after the header are sampled; if more than half of thecolumns + rows 
meet the criteria, [`True`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") is returned.


Note

This method is a rough heuristic and may produce both false positives andnegatives.

The `Sniffer` class has the following attribute:
preferred[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
The list of the delimiters preferred for breaking ties,in the order of preference.It 
can be modified.Its initial value is `[',', '\t', ';', ' ', ':']`.

An example for [`Sniffer`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") use:

Copy

```with open('example.csv', newline='') as csvfile:    dialect =
csv.Sniffer().sniff(csvfile.read(1024))    csvfile.seek(0)    reader = csv.reader(csvfile,
dialect)    # ... process CSV file contents here ...```

The `csv` module defines the following constants:
csv.QUOTE_ALL[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
Instructs [`writer`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") objects to quote all fields.
csv.QUOTE_MINIMAL[¶](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation")
Instructs [`writer`](../_static/pygments_dark.css?v=0fc419ee "Search within Python 3.14.7 documentation") objects to only quote those fields which containspecial characters such as
*delimiter*, *quotechar*, `'\r'`, `'\n'`or any of the characters in *lineterminator*.If
*doublequote* is [`False`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") and
*escapechar* is set,the *quotechar* is escaped instead of causing the field to be
quoted.
csv.QUOTE_NONNUMERIC[¶](../_static/opensearch.xml "Search within Python 3.14.7 documentation")
Instructs [`writer`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") objects to quote all non-numeric fields.

Instructs [`reader`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") objects to convert all non-quoted fields to type [`float`](../_static/opensearch.xml "Search within Python 3.14.7 documentation").


Note

Some numeric types, such as [`bool`](../_static/opensearch.xml "Search within Python 3.14.7 documentation"), [`Fraction`](../_static/opensearch.xml "Search within Python 3.14.7 documentation"),or [`IntEnum`](../_static/opensearch.xml "Search within Python 3.14.7 documentation"), have a string representation that cannot beconverted to [`float`](../_static/opensearch.xml "Search within Python 3.14.7 documentation").They cannot be read in the `QUOTE_NONNUMERIC`
and[`QUOTE_STRINGS`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") modes.
csv.QUOTE_NONE[¶](../_static/opensearch.xml "Search within Python 3.14.7 documentation")
Instructs [`writer`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") objects to never quote fields.When the current
*delimiter*, *quotechar*, *escapechar*, `'\r'`, `'\n'`or any of the characters in *lineterminator*
occurs in output datait is preceded by the current *escapechar* character.If *escapechar*
is not set, the writer will raise [`Error`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") ifany characters that require escaping are encountered.Set
*quotechar* to `None` to prevent its escaping.

Instructs [`reader`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") objects to perform no special processing of quote characters.
csv.QUOTE_NOTNULL[¶](../_static/opensearch.xml "Search within Python 3.14.7 documentation")
Instructs [`writer`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") objects to quote all fields which are
not`None`.  This is similar to [`QUOTE_ALL`](../_static/opensearch.xml "Search within Python 3.14.7 documentation"), except that if afield value is `None`
an empty (unquoted) string is written.

Instructs [`reader`](../_static/opensearch.xml "Search within Python 3.14.7 documentation") objects to interpret an empty (unquoted) fieldas `None`
and to otherwise behave as [`QUOTE_ALL`](../search.html "Search").


Added in version 3.12.
csv.QUOTE_STRINGS[¶](../_static/pydoctheme_dark.css "previous chapter")
Instructs [`writer`](../_static/pydoctheme_dark.css "previous chapter") objects to always place quotes around fieldswhich are strings.  This is similar to [`QUOTE_NONNUMERIC`](../_static/py.svg "previous chapter"), except that if afield value is `None`
an empty (unquoted) string is written.

Instructs [`reader`](../_static/py.svg "previous chapter") objects to interpret an empty (unquoted) string as `None`
andto otherwise behave as [`QUOTE_NONNUMERIC`](../_static/py.svg "previous chapter").


Added in version 3.12.

The `csv` module defines the following exception:
*exception *csv.Error[¶](../_static/py.svg "previous chapter")
Raised by any of the functions when an error is detected.

## Dialects and Formatting Parameters[¶](../_static/py.svg "previous chapter")

To make it easier to specify the format of input and output records, specificformatting
parameters are grouped together into dialects.  A dialect is asubclass of the [`Dialect`](../_static/py.svg "previous chapter") class containing various attributesdescribing the format of the CSV file.  When creating [`reader`](../_static/py.svg "previous chapter") or[`writer`](../_static/py.svg "previous chapter") objects, the programmer can specify a string or a subclass ofthe `Dialect`
class as the dialect parameter.  In addition to, or insteadof, the *dialect* parameter,
the programmer can also specify individualformatting parameters, which have the same
names as the attributes defined belowfor the `Dialect` class.

Dialects support the following attributes:
Dialect.delimiter[¶](../_static/py.svg "previous chapter")
A one-character string used to separate fields.  It defaults to `','`.
Dialect.doublequote[¶](https://www.python.org/ "previous chapter")
Controls how instances of *quotechar* appearing inside a field shouldthemselves be
quoted.  When [`True`](https://www.python.org/ "previous chapter"), the character is doubled. When[`False`](https://www.python.org/ "previous chapter"), the
*escapechar* is used as a prefix to the *quotechar*.  Itdefaults to `True`.

On output, if *doublequote* is [`False`](../contents.html "previous chapter") and no *escapechar*
is set,[`Error`](../contents.html "previous chapter") is raised if a *quotechar* is found
in a field.
Dialect.escapechar[¶](../contents.html "previous chapter")
A one-character string used by the writer to escape characters thatrequire escaping:

>
>
> - the *delimiter*, the *quotechar*, `'\r'`, `'\n'` and any of the
> characters in *lineterminator* are escaped if *quoting* is set to
> [`QUOTE_NONE`](../contents.html "previous chapter");
>
> - the *quotechar* is escaped if *doublequote* is [`False`](../contents.html "previous chapter");
>
> - the *escapechar* itself.
>
>

On reading, the *escapechar* removes any special meaning fromthe following character.
It defaults to [`None`](../contents.html "previous chapter"), which disables escaping.


Changed in version 3.10: Previously the *escapechar* itself was not escaped,which
lost it on reading.


Changed in version 3.11: An empty *escapechar* is not allowed.
Dialect.lineterminator[¶](../contents.html "previous chapter")
The string used to terminate lines produced by the [`writer`](../contents.html "previous chapter"). It defaultsto
`'\r\n'`.


Note

The [`reader`](#dialects-and-formatting-parameters "previous chapter") is hard-coded to recognise either `'\r'`
or `'\n'` asend-of-line, and ignores *lineterminator*. This behavior may change in thefuture.
Dialect.quotechar[¶](? "meta[property="og:title"]")
A one-character string used to quote fields containing special characters,such as
the *delimiter* or the *quotechar*, or which contain new-linecharacters (`'\r'`, `'\n'` or
any of the characters in *lineterminator*).It defaults to `'"'`.Can be set to `None` to
prevent escaping `'"'` if *quoting* is setto [`QUOTE_NONE`](../bugs.html ">Improve this page</a></li>
<li>
<a href=").


Changed in version 3.11: An empty *quotechar* is not allowed.
Dialect.quoting[¶](../genindex.html "General Index")
Controls when quotes should be generated by the writer and recognised by thereader.
It can take on any of the [QUOTE_\* constants](../py-modindex.html "Python Module Index")and defaults to [`QUOTE_MINIMAL`](configparser.html "configparser — Configuration file parser") if
*quotechar* is not `None`,and [`QUOTE_NONE`](https://www.python.org/ "Link to this heading") otherwise.
Dialect.skipinitialspace[¶](../index.html "Link to this heading")
When [`True`](../index.html "Link to this heading"), spaces immediately following the *delimiter*
are ignored.The default is [`False`](../index.html "Link to this heading").  When combining `delimiter=' '`
with`skipinitialspace=True`, unquoted empty fields are not allowed.
Dialect.strict[¶](../index.html "Link to this heading")
When `True`, raise exception [`Error`](../index.html "Link to this heading") on bad CSV input.The default is
`False`.

## Writer Objects[¶](../_static/pygments.css?v=b86133f3 "viewport")

[`writer`](../_static/pygments.css?v=b86133f3 "viewport") objects ([`DictWriter`](../_static/pygments.css?v=b86133f3 "highlight-") instances and objects returned bythe [`writer()`](../_static/classic.css?v=234b1a7c "highlight-") function) have the following public methods.  A
*row* must bean iterable of strings or numbers for `writer` objects and a dictionarymapping
fieldnames to strings or numbers (by passing them through [`str()`](../_static/classic.css?v=234b1a7c "highlight-")first) for `DictWriter`
objects.  Note that complex numbers are writtenout surrounded by parens. This may
cause some problems for other programs whichread CSV files (assuming they support
complex numbers at all).
csvwriter.writerow(*row*, */*)[¶](../_static/classic.css?v=234b1a7c "highlight-")
Write the *row* parameter to the writer’s file object, formatted accordingto the
current [`Dialect`](../_static/classic.css?v=234b1a7c "highlight-"). Return the return value of the call to
the*write* method of the underlying file object.


Changed in version 3.5: Added support of arbitrary iterables.
csvwriter.writerows(*rows*, */*)[¶](../_static/classic.css?v=234b1a7c "highlight-")
Write all elements in *rows* (an iterable of *row* objects as describedabove) to
the writer’s file object, formatted according to the currentdialect.

Writer objects have the following public attribute:
csvwriter.dialect[¶](../_static/classic.css?v=234b1a7c "highlight-")
A read-only description of the dialect in use by the writer.

DictWriter objects have the following public method:
DictWriter.writeheader()[¶](../_static/classic.css?v=234b1a7c "highlight-")
Write a row with the field names (as specified in the constructor) tothe writer’s
file object, formatted according to the current dialect. Returnthe return value of
the [`csvwriter.writerow()`](../_static/classic.css?v=234b1a7c "highlight-") call used internally.


Added in version 3.2.


Changed in version 3.8: `writeheader()` now also returns the value returned bythe [`csvwriter.writerow()`](../_static/classic.css?v=234b1a7c "highlight-") method it uses internally.

## Examples[¶](../_static/pydoctheme.css?v=4365c8fe "highlight-")

The simplest example of reading a CSV file:

Copy

```import csvwith open('some.csv', newline='') as f:    reader = csv.reader(f)   
 for row in reader:        print(row)```

Reading a file with an alternate format:

Copy

```import csvwith open('passwd', newline='') as f:    reader = csv.reader(f, delimiter=':',
quoting=csv.QUOTE_NONE)    for row in reader:        print(row)```

The corresponding simplest possible writing example is:

Copy

```import csvwith open('some.csv', 'w', newline='') as f:    writer = csv.writer(f) 
   writer.writerows(someiterable)```

Since [`open()`](../_static/pydoctheme.css?v=4365c8fe "highlight-") is used to open a CSV file for reading, the filewill by default be decoded into unicode using the system defaultencoding (see [`locale.getencoding()`](../_static/pydoctheme.css?v=4365c8fe "highlight-")).  To decode a fileusing a different encoding, use the `encoding` 
argument of open:

Copy

```import csvwith open('some.csv', newline='', encoding='utf-8') as f:    reader
= csv.reader(f)    for row in reader:        print(row)```

The same applies to writing in something other than the system defaultencoding: specify
the encoding argument when opening the output file.

Registering a new dialect:

Copy

```import csvcsv.register_dialect('unixpwd', delimiter=':', quoting=csv.QUOTE_NONE)with 
open('passwd', newline='') as f:    reader = csv.reader(f, 'unixpwd')```

A slightly more advanced use of the reader — catching and reporting errors:

Copy

```import csv, sysfilename = 'some.csv'with open(filename, newline='') as f:    reader
= csv.reader(f)    try:        for row in reader:            print(row)    except
csv.Error as e:        sys.exit(f'file {filename}, line {reader.line_num}: {e}')```

And while the module doesn’t directly support parsing strings, it can easily bedone:

Copy

```import csvfor row in csv.reader(['one,two,three']):    print(row)```
