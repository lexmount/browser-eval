# `asyncio` — Asynchronous I/O[¶](#module-asyncio "Link to this heading")

---

Hello World!

Copy

```import asyncioasync def main():    print('Hello ...')    await asyncio.sleep(1) 
   print('... World!')asyncio.run(main())```

asyncio is a library to write **concurrent** code usingthe **async/await** syntax.

asyncio is used as a foundation for multiple Python asynchronousframeworks that provide 
high-performance network and web-servers,database connection libraries, distributed 
task queues, etc.

asyncio is often a perfect fit for IO-bound and high-level**structured** network 
code.


See also
[A Conceptual Overview of asyncio](../_static/pygments.css?v=b86133f3 "viewport")
Explanation of the fundamentals of asyncio.

asyncio provides a set of **high-level** APIs to:

- [run Python coroutines](../_static/pygments.css?v=b86133f3 "viewport") concurrently andhave full control over their execution;
- perform [network IO and IPC](../_static/pygments.css?v=b86133f3 "viewport");
- control [subprocesses](../_static/pygments.css?v=b86133f3 "viewport");
- distribute tasks via [queues](../_static/pygments.css?v=b86133f3 "viewport");
- [synchronize](../_static/pygments.css?v=b86133f3 "viewport") concurrent code;

For **introspection**, asyncio provides APIs and tools for:

- inspecting the [async call graph](../_static/pygments.css?v=b86133f3 "viewport") of tasks and futures;
- inspecting tasks in another running Python process with[command-line tools](../_static/classic.css?v=234b1a7c "highlight-");

Additionally, there are **low-level** APIs for*library and framework developers* 
to:

- create and manage [event loops](../_static/classic.css?v=234b1a7c "highlight-"), whichprovide asynchronous APIs for [networking](../_static/classic.css?v=234b1a7c "highlight-"),running [subprocesses](../_static/classic.css?v=234b1a7c "highlight-"),handling [OS signals](../_static/classic.css?v=234b1a7c "highlight-"), etc;
- implement efficient protocols using[transports](../_static/classic.css?v=234b1a7c "highlight-");
- [bridge](../_static/classic.css?v=234b1a7c "highlight-") callback-based libraries and codewith async/await syntax.


[Availability](../_static/classic.css?v=234b1a7c "highlight-"): not WASI.

This module does not work or is not available on WebAssembly. See[WebAssembly platforms](../_static/classic.css?v=234b1a7c "highlight-") for more information.

asyncio REPL

You can experiment with an `asyncio` concurrent context in the [REPL](../_static/classic.css?v=234b1a7c "highlight-"):

Copy

```$ python -m asyncioasyncio REPL ...Use "await" directly instead of "asyncio.run()".Type
"help", "copyright", "credits" or "license" for more information.>>> import
asyncio>>> await asyncio.sleep(10, result='hello')'hello'```

This REPL provides limited compatibility with [`PYTHON_BASIC_REPL`](../_static/classic.css?v=234b1a7c "highlight-").It is recommended that the default REPL is usedfor full functionality and the latest features.

Raises an [auditing event](../_static/classic.css?v=234b1a7c "highlight-") `cpython.run_stdin` with
no arguments.


Changed in version 3.12.5: (also 3.11.10, 3.10.15, 3.9.20, and 3.8.20)Emits audit
events.


Changed in version 3.13: Uses PyREPL if possible, in which case [`PYTHONSTARTUP`](../_static/classic.css?v=234b1a7c "highlight-") isalso executed. Emits audit events.
