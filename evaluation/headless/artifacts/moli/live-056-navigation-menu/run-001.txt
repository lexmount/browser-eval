[Deno](/login?return_to=https%3A%2F%2Fgithub.com%2Fdenoland%2Fdeno "_R_5knd_")([/ˈdiːnoʊ/](/login?return_to=https%3A%2F%2Fgithub.com%2Fdenoland%2Fdeno "_R_5knd_"),
pronounced`dee-no`) is a JavaScript, TypeScript, and WebAssembly runtime with securedefaults
and a great developer experience. It's built on [V8](/login?return_to=https%3A%2F%2Fgithub.com%2Fdenoland%2Fdeno "_R_5knd_"),[Rust](/login?return_to=https%3A%2F%2Fgithub.com%2Fdenoland%2Fdeno "_R_5knd_"), and [Tokio](/login?return_to=https%3A%2F%2Fgithub.com%2Fdenoland%2Fdeno "_R_5knd_").

Learn more about the Deno runtime[in the documentation](/login?return_to=https%3A%2F%2Fgithub.com%2Fdenoland%2Fdeno "_R_5knd_").


## Installation

Install the Deno runtime on your system using one of the commands below. Notethat
there are a number of ways to install Deno - a comprehensive list ofinstallation
options can be found[here](https://github.com/features/copilot "_R_5knd_").

Shell (Mac, Linux):

```curl -fsSL https://deno.land/install.sh | sh```

                              
PowerShell (Windows):

```irm https://deno.land/install.ps1 | iex```


[Homebrew](https://github.com/features/copilot "Octicon") (Mac):

```brew install deno```

                              
[Chocolatey](https://github.com/features/ai/github-app "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0") (Windows):

```choco install deno```


[WinGet](https://github.com/mcp "Octicon") (Windows):

```winget install --id=DenoLand.Deno```

                              
[Scoop](https://github.com/mcp "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0")(Windows):

```scoop install main/deno```

## Your first Deno program

Deno can be used for many different applications, but is most commonly used tobuild
web servers. Create a file called `server.ts` and include the followingTypeScript code:

```Deno.serve((_req: Request) => {  return new Response("Hello, world!");});```

                              
Run your server with the following command:

```deno run --allow-net server.ts```


This should start a local web server on[http://localhost:8000](https://github.com/features/code-review "Octicon").

Learn more about writing and running Deno programs[in the docs](https://github.com/features/code-review "Octicon").
