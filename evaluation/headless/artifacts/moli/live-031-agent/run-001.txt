maxAgeHours

integer | null


Maximum age of cached content in hours. Positive values use cached content if it
is less than this many hours old; 0 fetches fresh content and is the supported way
to apply text rendering options to newly fetched pages; -1 always uses cache; omitted
uses fallback fetching when cached content is unavailable. Maximum supported value
is 720 hours.

Required range: `-1 <= x <= 720`

Example:


`24`
