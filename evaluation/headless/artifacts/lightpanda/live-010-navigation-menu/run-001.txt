[Scrapy](https://github.githubassets.com/assets/t7l-0a8b07066f584f39.js "route-pattern") is a web scraping framework to extract structured data from websites.It is cross-platform, and requires Python 3.10+. It is maintained by [Zyte](https://github.githubassets.com/assets/wsr-5fd3071e5a9061ab.js "route-pattern")(formerly Scrapinghub) and [many other contributors](https://github.githubassets.com/assets/ps6-ccbe0db236f6e22f.js "route-pattern").

Install with:

```pip install scrapy```

And follow the [documentation](https://github.githubassets.com/assets/j8s-d6df66de8459f530.js "route-pattern") to learn how to use it.

If you wish to contribute, see [Contributing](https://github.githubassets.com/assets/la-de176c4ee471f2b3.js "route-pattern").
