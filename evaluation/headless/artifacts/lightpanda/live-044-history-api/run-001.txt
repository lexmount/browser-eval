# History API


Baseline                                      Widely
available                                                                        


This feature is well established and works across many devices and browser versions.
It’s been available across browsers since July 2015.

-             [              Learn more            ](/en-US/docs/Web/HTML/Guides/Responsive_images "See all HTML references")          
-             [              See full compatibility            ](/en-US/docs/Web/HTML/Guides/Responsive_images "See all HTML guides")          


The **History API** provides access to the browser's session history (not to be confused
with [WebExtensions history](/en-US/docs/Web/HTML/Guides/Date_and_time_formats "See all HTML guides")) through the [`history`](/en-US/docs/Web/HTML/Guides/Date_and_time_formats "See all HTML guides") global object. It exposes useful methods and properties that let you navigate back and forth through the user's history, and manipulate the contents of the history stack.


**Note:**This API is only available on the main thread ([`Window`](/en-US/docs/Web/SVG "See all HTML guides")). It cannot be accessed in [`Worker`](/en-US/docs/Web/SVG "/en-US/docs/Web/CSS") or [`Worklet`](/en-US/docs/Web/SVG "/en-US/docs/Web/CSS") contexts.

## [Concepts and usage](/en-US/docs/Web/CSS "/en-US/docs/Web/CSS")

Moving backward and forward through the user's history is done using the [`back()`](/en-US/docs/Web/CSS/Reference/Properties "See all CSS references"), [`forward()`](/en-US/docs/Web/CSS/Reference/Properties "See all CSS references"), and [`go()`](/en-US/docs/Web/CSS/Reference/Properties "See all CSS references") methods.

### [Moving forward and backward](/en-US/docs/Web/CSS/Reference/Selectors "See all CSS references")

To move backward through history:

js

```menu__tab
history.back();
```

This acts exactly as if the user clicked on the **Back** button in their browser
toolbar.

Similarly, you can move forward (as if the user clicked the **Forward** button),
like this:

js

```menu__tab
history.forward();
```

### [Moving to a specific point in history](/en-US/docs/Web/CSS/Guides/Box_model/Introduction "See all CSS guides")

You can use the [`go()`](/en-US/docs/Web/CSS/Guides/Box_model/Introduction "See all CSS guides") method to load a specific page from session history, identified by its relative position to the current page. (The current page's relative position is
`0`.)

To move back one page (the equivalent of calling [`back()`](/en-US/docs/Web/CSS/Guides/Animations/Using "See all CSS guides")):

js

```menu__tab
history.go(-1);
```

To move forward a page, just like calling [`forward()`](/en-US/docs/Web/CSS/Guides/Colors/Applying_color "See all CSS guides"):

js

```menu__tab
history.go(1);
```

Similarly, you can move forward 2 pages by passing `2`, and so forth.

Another use for the `go()` method is to refresh the current page by either passing `0`,
or by invoking it without an argument:

js

```menu__tab
// The following statements
// both have the effect of
// refreshing the page
history.go(0);
history.go();
```

You can determine the number of pages in the history stack by looking at the value
of the `length` property:

js

```menu__tab
const numberOfEntries = history.length;
```

## [Interfaces](/en-US/docs/Web/CSS/How_to/Layout_cookbook/Card "/en-US/docs/Web/JavaScript")
[`History`](/en-US/docs/Web/CSS/How_to/Layout_cookbook/Card "/en-US/docs/Web/JavaScript")
Allows manipulation of the browser *session history* (that is, the pages visited
in the tab or frame that the current page is loaded in).
[`PopStateEvent`](/en-US/docs/Web/CSS/How_to/Layout_cookbook "/en-US/docs/Web/JavaScript")
The interface of the [`popstate`](/en-US/docs/Web/JavaScript "/en-US/docs/Web/JavaScript") event.

## [Examples](/en-US/docs/Web/JavaScript "/en-US/docs/Web/JavaScript")

The following example assigns a listener for the [`popstate`](/en-US/docs/Web/JavaScript "/en-US/docs/Web/JavaScript") event. It then illustrates some of the methods of the history object to add, replace, and move within the browser history for the current tab.

js

```menu__panel
window.addEventListener("popstate", (event) => {
  alert(
    `location: ${document.location}, state: ${JSON.stringify(event.state)}`,
  );
});

history.pushState({ page: 1 }, "title 1", "?page=1");
history.pushState({ page: 2 }, "title 2", "?page=2");
history.replaceState({ page: 3 }, "title 3", "?page=3");
history.back(); // alerts "location: http://example.com/example.html?page=1, state: {"page":1}"
history.back(); // alerts "location: http://example.com/example.html, state: null"
history.go(2); // alerts "location: http://example.com/example.html?page=3, state: {"page":3}"
```
