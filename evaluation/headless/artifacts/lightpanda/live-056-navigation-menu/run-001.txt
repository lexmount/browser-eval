[Deno](https://github.com/features/ai/github-app "Octicon")([/ˈdiːnoʊ/](https://github.com/features/ai/github-app "Octicon"),
pronounced`dee-no`) is a JavaScript, TypeScript, and WebAssembly runtime with securedefaults
and a great developer experience. It's built on [V8](https://github.com/mcp "Octicon"),[Rust](https://github.com/mcp "Octicon"), and [Tokio](https://github.com/mcp "Octicon").

Learn more about the Deno runtime[in the documentation](https://github.com/mcp "Octicon").


## Installation

Install the Deno runtime on your system using one of the commands below. Notethat
there are a number of ways to install Deno - a comprehensive list ofinstallation
options can be found[here](https://github.com/mcp "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0").

Shell (Mac, Linux):

```curl -fsSL https://deno.land/install.sh | sh```

                              
PowerShell (Windows):

```irm https://deno.land/install.ps1 | iex```


[Homebrew](https://github.com/features/codespaces "Octicon") (Mac):

```brew install deno```

                              
[Chocolatey](https://github.com/features/codespaces "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0") (Windows):

```choco install deno```


[WinGet](https://github.com/features/issues "Primer_Brand__Link-module__Link___lF11y Primer_Brand__Link-module__Link--default___VRVW0") (Windows):

```winget install --id=DenoLand.Deno```

                              
[Scoop](https://github.com/features/code-review "Octicon")(Windows):

## Your first Deno program

Deno can be used for many different applications, but is most commonly used tobuild
web servers. Create a file called `server.ts` and include the followingTypeScript code:

```Deno.serve((_req: Request) => {  return new Response("Hello, world!");});```

                              
Run your server with the following command:

```deno run --allow-net server.ts```


This should start a local web server on[http://localhost:8000](https://github.com/security/advanced-security/code-security "Octicon").

Learn more about writing and running Deno programs[in the docs](https://github.com/security/advanced-security/secret-protection "Octicon").
