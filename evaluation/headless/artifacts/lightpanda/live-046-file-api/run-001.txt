## [Concepts and Usage](/en-US/docs/Web/HTML "/en-US/docs/Web/HTML")

The File API enables web applications to access files and their contents.

Web applications can access files when the user makes them available, either using
a [file `<input>` element](/en-US/docs/Web/HTML "/en-US/docs/Web/HTML") or [via drag and drop](/en-US/docs/Web/HTML "/en-US/docs/Web/HTML").

Sets of files made available in this way are represented as [`FileList`](/en-US/docs/Web/HTML "/en-US/docs/Web/HTML") objects, which enable a web application to retrieve individual [`File`](/en-US/docs/Web/HTML "/en-US/docs/Web/HTML") objects. In turn [`File`](/en-US/docs/Web/HTML "/en-US/docs/Web/HTML") objects provide access to metadata such as the file's name, size, type, and last modified date.

[`File`](/en-US/docs/Web/HTML/Reference/Elements "See all HTML references") objects can be passed to [`FileReader`](/en-US/docs/Web/HTML/Reference/Elements "See all HTML references") objects to access the contents of the file. The [`FileReader`](/en-US/docs/Web/HTML/Reference/Elements "See all HTML references") interface is asynchronous, but a synchronous version, available only in [web workers](/en-US/docs/Web/HTML/Reference/Global_attributes "See all HTML references"), is provided by the [`FileReaderSync`](/en-US/docs/Web/HTML/Reference/Global_attributes "See all HTML references") interface.

## [Relationship to other file-related APIs](/en-US/docs/Web/HTML/Reference/Attributes "See all HTML references")

There are two other major APIs that also deal with files: [File and Directory Entries API](/en-US/docs/Web/HTML/Reference "See all HTML references") and [File System API](/en-US/docs/Web/HTML/Guides/Responsive_images "See all HTML references").

The File API is the most basic one. It supports reading and processing file data
explicitly provided by the user in the form of a form element input or drag-and-drop
operation. It also enables binary data handling via blobs.

The File and Directory Entries API, like the File API, also deals with files provided
by the user via form inputs or drag-and-drop operations. However, instead of a single
file, the input element now allows the selection of a directory or multiple files.
The API then provides a way to process the directory or files. It is mostly Chrome's
own invention—you will find that its extensions to other interfaces are all prefixed
with `webkit`. The [File and Directory Entries API](/en-US/docs/Web/HTML/Guides/Date_and_time_formats "See all HTML guides") has a more complete story about its implementation and standardization. It was originally intended to support a full virtual file system, but now only supports read operations on user-provided data.

The File System API provides a virtual file system for web applications, so that
they can persistently store data in a virtual system which is private to the document's
origin (known as an [Origin private file system (OPFS)](/en-US/docs/Web/SVG "See all HTML guides")). The File System Access API further extends the File System API to allow websites to read and write user files, subject to user consent. Unlike the File API and the File and Directory Entries API, the File System API is purely JavaScript and does not deal with form inputs.

## [Interfaces](/en-US/docs/Web/MathML "/en-US/docs/Web/CSS")
[`Blob`](/en-US/docs/Web/XML "/en-US/docs/Web/CSS")
Represents a "Binary Large Object", meaning a file-like object of immutable, raw
data; a [`Blob`](/en-US/docs/Web/CSS "/en-US/docs/Web/CSS") can be read as text or binary data, or converted into a [`ReadableStream`](/en-US/docs/Web/CSS "/en-US/docs/Web/CSS") so its methods can be used for processing the data.
[`File`](/en-US/docs/Web/CSS "/en-US/docs/Web/CSS")
Provides information about a file and allows JavaScript in a web page to access its
content.
[`FileList`](/en-US/docs/Web/CSS "/en-US/docs/Web/CSS")
Returned by the `files` property of the HTML [`<input>`](/en-US/docs/Web/CSS "/en-US/docs/Web/CSS") element; this lets you access the list of files selected with the `<input type="file">`
element. It's also used for a list of files dropped into web content when using the
drag and drop API; see the [`DataTransfer`](/en-US/docs/Web/CSS "See all CSS references") object for details on this usage.
[`FileReader`](/en-US/docs/Web/CSS/Reference/Properties "See all CSS references")
Enables web applications to asynchronously read the contents of files (or raw data
buffers) stored on the user's computer, using [`File`](/en-US/docs/Web/CSS/Reference/Properties "See all CSS references") or [`Blob`](/en-US/docs/Web/CSS/Reference/Selectors "See all CSS references") objects to specify the file or data to read.
[`FileReaderSync`](/en-US/docs/Web/CSS/Reference/Selectors "See all CSS references")
Enables web applications to synchronously read the contents of files (or raw data
buffers) stored on the user's computer, using [`File`](/en-US/docs/Web/CSS/Reference/At-rules "See all CSS references") or [`Blob`](/en-US/docs/Web/CSS/Reference/At-rules "See all CSS references") objects to specify the file or data to read.

### [Extensions to other interfaces](/en-US/docs/Web/CSS/Reference "See all CSS references")
[`URL.createObjectURL()`](/en-US/docs/Web/CSS/Guides/Box_model/Introduction "See all CSS references")
Creates a URL that can be used to fetch a [`File`](/en-US/docs/Web/CSS/Guides/Box_model/Introduction "See all CSS guides") or [`Blob`](/en-US/docs/Web/CSS/Guides/Box_model/Introduction "See all CSS guides") object.
[`URL.revokeObjectURL()`](/en-US/docs/Web/CSS/Guides/Box_model/Introduction "See all CSS guides")
Releases an existing object URL which was previously created by calling [`URL.createObjectURL()`](/en-US/docs/Web/CSS/Guides/Animations/Using "See all CSS guides").

## [Examples](/en-US/docs/Web/CSS/Guides/Flexible_box_layout/Basic_concepts "See all CSS guides")

### [Reading a file](/en-US/docs/Web/CSS/Guides/Colors/Applying_color "See all CSS guides")

In this example, we provide a [file `<input>` element](/en-US/docs/Web/CSS/Guides "See all CSS guides"), and when the user selects a file, we read the contents of the first file selected as text, and display the result in a [`<div>`](/en-US/docs/Web/CSS/How_to/Layout_cookbook/Column_layouts "See all CSS guides").

#### HTML

html

```menu__tab
<input type="file" />
<div class="output"></div>
```

#### CSS

css

```menu__tab
.output {
  overflow: scroll;
  margin: 1rem 0;
  height: 200px;
}
```

#### JavaScript

js

```menu__tab
const fileInput = document.querySelector("input[type=file]");
const output = document.querySelector(".output");

fileInput.addEventListener("change", async () => {
  const [file] = fileInput.files;

  if (file) {
    output.innerText = await file.text();
  }
});
```
