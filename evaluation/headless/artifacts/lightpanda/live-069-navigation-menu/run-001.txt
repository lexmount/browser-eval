## Intro

Prettier is an opinionated code formatter. It enforces a consistent style by parsing
your code and re-printing it with its own rules that take the maximum line length
into account, wrapping code when necessary.


### Input

```foo(reallyLongArg(), omgSoManyParameters(), IShouldRefactorThis(), isThereSeriouslyAnotherOne());```

                              


### Output

```foo(  reallyLongArg(),  omgSoManyParameters(),  IShouldRefactorThis(),
isThereSeriouslyAnotherOne(),);```


Prettier can be run [in your editor](https://github.githubassets.com/assets/7cv-ee517aa478d5e709.js "route-pattern") on-save, in a [pre-commit hook](https://github.githubassets.com/assets/4b-7787ae6d29e0c1d8.js "route-pattern"), or in [CI environments](https://github.githubassets.com/assets/4b-7787ae6d29e0c1d8.js "route-pattern") to ensure your codebase has a consistent style without devs ever having to post a nit-picky comment on a code review ever again!
