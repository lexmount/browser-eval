<div class="admonition seealso">
<p class="admonition-title">See also</p>
<p>If you’re new to <a class="reference external" href="https://www.python.org/">Python</a>, you might want to start by getting an idea of
what the language is like. Django is 100% Python, so if you’ve got minimal
comfort with Python you’ll probably get a lot more out of Django.</p>
<p>If you’re new to programming entirely, you might want to start with this
<a class="reference external" href="https://wiki.python.org/moin/BeginnersGuide/NonProgrammers">list of Python resources for non-programmers</a></p>
<p>If you already know a few other languages and want to get up to speed with
Python quickly, we recommend referring to the official
<a class="reference external" href="https://docs.python.org/3/">Python documentation</a>, which provides comprehensive and authoritative
information about the language, as well as links to other resources such as
a list of <a class="reference external" href="https://wiki.python.org/moin/PythonBooks">books about Python</a>.</p>
