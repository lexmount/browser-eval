<h2 class="anchor anchorTargetStickyNavbar_uzTO" id=installing-pnpm-12>Installing pnpm 12<a href=#installing-pnpm-12 class=hash-link aria-label="Direct link to Installing pnpm 12" title="Direct link to Installing pnpm 12" translate=no>​</a></h2>
<p>pnpm 12, the Rust rewrite, is stable since v12.0.0 (August 26, 2026). Please <a href=https://github.com/pnpm/pnpm/issues target=_blank rel="noopener noreferrer" class="">report any issues</a> you run into.</p>
<p>Apart from a short list of differences, pnpm 12 does not change the way you use pnpm 11, so the rest of this documentation applies to both versions — see <a class="" href=/blog/whats-different-in-pnpm-12>What's different in pnpm 12</a>. Only installation differs: <code>latest</code> on npm still points at the pnpm 11 line, so pnpm 12 is installed from the <code>next-12</code> tag, and Homebrew, winget, Scoop and Chocolatey don't offer it yet.</p>
<h3 class="anchor anchorTargetStickyNavbar_uzTO" id=pnpm-12-using-pnpm>Using pnpm<a href=#pnpm-12-using-pnpm class=hash-link aria-label="Direct link to Using pnpm" title="Direct link to Using pnpm" translate=no>​</a></h3>
<p>If you already have pnpm v11.10.0 or newer, this is the easiest way to switch:</p>
<div class="language-text codeBlockContainer_rlFr theme-code-block" style=--prism-color:#393A34;--prism-background-color:#f6f8fa><div class=codeBlockContent_qRwH><pre tabindex=0 class="prism-code language-text codeBlock_DOCH thin-scrollbar" style=color:#393A34;background-color:#f6f8fa><code class=codeBlockLines_d4DD><div class=token-line style=color:#393A34><span class="token plain">pnpm self-update next-12</span><br/></div></code></pre></div></div>
<p>pnpm links the native binary directly, so nothing else is needed. Note that inside a project that pins pnpm through the <code>packageManager</code> field, <a class="" href=/cli/self-update><code>self-update</code></a> only updates that pin instead of installing pnpm globally.</p>
<h3 class="anchor anchorTargetStickyNavbar_uzTO" id=pnpm-12-using-npm>Using npm<a href=#pnpm-12-using-npm class=hash-link aria-label="Direct link to Using npm" title="Direct link to Using npm" translate=no>​</a></h3>
<p>If you don't have pnpm installed yet:</p>
<div class="language-sh codeBlockContainer_rlFr theme-code-block" style=--prism-color:#393A34;--prism-background-color:#f6f8fa><div class=codeBlockContent_qRwH><pre tabindex=0 class="prism-code language-sh codeBlock_DOCH thin-scrollbar" style=color:#393A34;background-color:#f6f8fa><code class=codeBlockLines_d4DD><div class=token-line style=color:#393A34><span class="token plain">npx get-pnpm next-12</span><br/></div></code></pre></div></div>
<p>Node.js 22.13 or newer is needed to run that install script, but not to run pnpm afterwards — pnpm 12 is a native binary.</p>
<h3 class="anchor anchorTargetStickyNavbar_uzTO" id=pnpm-12-using-a-standalone-script>Using a standalone script<a href=#pnpm-12-using-a-standalone-script class=hash-link aria-label="Direct link to Using a standalone script" title="Direct link to Using a standalone script" translate=no>​</a></h3>
<p>Set <code>PNPM_VERSION</code> to <code>next-12</code>, or to an exact version.</p>
<p>On POSIX systems:</p>
<div class="language-sh codeBlockContainer_rlFr theme-code-block" style=--prism-color:#393A34;--prism-background-color:#f6f8fa><div class=codeBlockContent_qRwH><pre tabindex=0 class="prism-code language-sh codeBlock_DOCH thin-scrollbar" style=color:#393A34;background-color:#f6f8fa><code class=codeBlockLines_d4DD><div class=token-line style=color:#393A34><span class="token function" style=color:#d73a49>curl</span><span class="token plain"> </span><span class="token parameter variable" style=color:#36acaa>-fsSL</span><span class="token plain"> https://get.pnpm.io/install.sh </span><span class="token operator" style=color:#393A34>|</span><span class="token plain"> </span><span class="token function" style=color:#d73a49>env</span><span class="token plain"> </span><span class="token assign-left variable" style=color:#36acaa>PNPM_VERSION</span><span class="token operator" style=color:#393A34>=</span><span class="token plain">next-12 </span><span class="token function" style=color:#d73a49>sh</span><span class="token plain"> -</span><br/></div></code></pre></div></div>
<p>On Windows, using PowerShell:</p>
<div class="language-powershell codeBlockContainer_rlFr theme-code-block" style=--prism-color:#393A34;--prism-background-color:#f6f8fa><div class=codeBlockContent_qRwH><pre tabindex=0 class="prism-code language-powershell codeBlock_DOCH thin-scrollbar" style=color:#393A34;background-color:#f6f8fa><code class=codeBlockLines_d4DD><div class=token-line style=color:#393A34><span class="token variable" style=color:#36acaa>$env</span><span class="token plain">:PNPM_VERSION=</span><span class="token string" style=color:#e3116c>"next-12"</span><span class="token punctuation" style=color:#393A34>;</span><span class="token plain"> </span><span class="token function" style=color:#d73a49>Invoke-WebRequest</span><span class="token plain"> https:</span><span class="token operator" style=color:#393A34>/</span><span class="token operator" style=color:#393A34>/</span><span class="token plain">get</span><span class="token punctuation" style=color:#393A34>.</span><span class="token plain">pnpm</span><span class="token punctuation" style=color:#393A34>.</span><span class="token plain">io/install</span><span class="token punctuation" style=color:#393A34>.</span><span class="token plain">ps1 </span><span class="token operator" style=color:#393A34>-</span><span class="token plain">UseBasicParsing </span><span class="token punctuation" style=color:#393A34>|</span><span class="token plain"> </span><span class="token function" style=color:#d73a49>Invoke-Expression</span><br/></div></code></pre></div></div>
<p>This installs pnpm without requiring Node.js, and unlike pnpm 11 it also works on Intel macOS.</p>
