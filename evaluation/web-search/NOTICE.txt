SimpleQA Verified factual retrieval probes
------------------------------------------
Source: Google DeepMind / Google Research, SimpleQA Verified
Authors: Lukas Haas, Gal Yona, Giovanni D'Antonio, Sasha Goldshtein, Dipanjan Das
Dataset revision: ed392714d14fa5225b07c2b456453983bc75f690
Dataset: https://huggingface.co/datasets/google/simpleqa-verified
Report: https://arxiv.org/abs/2509.07968
The pinned dataset card declares the MIT license.

The search profile retains the original question, reference answer and supporting
URLs for all 831 questions within the shared 128-character input limit. The other
169 questions were excluded before collection. These are adapted retrieval probes,
not official SimpleQA Verified scores: the original benchmark evaluates parametric
knowledge without search or retrieval tools. Source-URL and literal-answer checks
are reported separately and do not replace semantic answer grading.
