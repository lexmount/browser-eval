# 风控100例规则完整性复核（2026-09-29）

## 复核目的与边界

本轮专门检查规则是否可能让“只取得页面一部分”的结果通过。100例均重新查看各自绑定的独立保存首次加载证据，并核对人类规则、正文分区、列表组合契约和机器配置。没有使用 Moli 输出制定或放宽规则，没有新增产品调用，也没有使用 Browser Use。

“首次加载就出现”只决定一段文字是否有资格被考虑，不表示页面上的每个词都要冻结。稳定文字还必须预计不会轻易变化、符合目标语言和范围，并能帮助识别页面或发现缺失区域。当前选中状态、账号状态、实验标签、统计值、价格、排名和当前列表成员等易变内容不纳入。

固定文章、文档和说明页应覆盖首次加载时已提供的完整目标正文；变化列表继续用真实链接或同条目字段、路径、去重和数量核对，不能冻结某次观察的名单。

## 复核结果

- 100例的绑定保存证据全部存在并参与本轮复核。
- 79例具有正文覆盖契约；固定文章、文档和说明页按声明的完整目标范围分区，不能只取开头。没有发现知乎之外新的“只覆盖文章开头”问题。
- 95例补入了首次加载证据中的合格页面外围稳定文字，包括顶部导航、侧栏、页面操作、固定页脚或普通文字按钮；共5例无需补充：`risk-006`、`risk-diverse-027`、`risk-diverse-038`、`risk-diverse-113`、`risk-diverse-193`。
- 全页面补充阶段把稳定文字从724项增加到1597项，净增873项。随后严格复核并拆分人工拼接项、删除归一化重复项，当前最终为1599项。
- 变化列表的 name-link、路径、同条目字段、去重和数量规则没有改成固定名单，也没有根据名称或ID猜测链接。
- `risk-011` 今日头条的资格描述由“正文开头”改为首次加载的完整文章范围，使资格说明与既有5区全文规则一致。

### risk-diverse-038 ArchWiki

## 稳定文字严格复核

针对“文字是否真的来自网页、是否把多个元素错误拼成一句”的质疑，又对100例全部1597项重新核对。新门槛不再删除所有标点后查找，而是只容忍 Unicode 等价、大小写、普通空格和换行差异；每项必须在该例绑定的保存正文中连续出现。同一案例中归一化后相同的文字也禁止重复登记。

- 此前新增的873项中，872项直接以相同字符出现在保存正文；`New Account` 的唯一差异是网页使用了不换行空格，不是人工拼接。
- 7例存在人工合成文字并已拆分或删除：`risk-diverse-032`、`risk-diverse-038`、`risk-diverse-042`、`risk-diverse-049`、`risk-diverse-050`、`risk-diverse-059`、`risk-diverse-101`。
- 5例存在大小写归一化后重复登记并已去重：`risk-061`、`risk-diverse-034`、`risk-diverse-040`、`risk-diverse-114`、`risk-diverse-267`。
- 例如 `enlightenment / enlightenment`、`devuan / installer-iso`、`index : current` 不再把分开的面包屑和分隔符合成一句；Arch Linux Packages 的八个表头改为逐项检查；`The pool Directory` 这一人工组合直接删除，其所在分区仍由完整正文规则覆盖。
- 严格复核后的1599项全部通过连续原文检查，且100例均不存在归一化重复项。配置生成器和回归测试已经加入这两项强制门槛。
- 其中1582项与保存文本逐字连续相同；其余17项只涉及正常换行、不换行空格或一句话中的内联链接，例如 `New Account` 的不换行空格。这17项仍是网页上的一个自然标签或连续句子，没有再把面包屑、表头或不同栏目人为合并。
