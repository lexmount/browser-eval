步骤的严格定义

一步 = 一次 CowAgent BrowserTool 等价调用，例如 navigate、click、get_text、fill、select、scroll、back 或 forward。等待页面就绪和目标值出现属于该工具调用内部，不单列、不计步。每次调用的参数、耗时、输出和状态写入执行轨迹。

成功判定：两个独立程序指标

  1. 结果正确（主指标）：每个标注输出与 expected_outputs 做严格字符串相等；不存在最低长度、模糊包含或 LLM 主观评分。
  2. 结果与参考过程均正确（辅指标）：在结果正确之外，本轮被重放的参考动作序列还必须与 expected_actions 一致，且全部 BrowserTool 调用成功。
  3. 失败复核：失败时可重复执行以补充同任务证据；报告仍只给每个任务一个结果，不把复核记录当成新任务或另一套正确率。

边界：expected_actions 是工具层微基准的固定参考路径，不代表任务只有一种解法。若评测自由规划 CowAgent，应把过程判定改成必要里程碑、禁止动作和步数预算，不能要求整条序列逐步相等。

模型与执行边界

  • 浏览器工具层（本报告主体）：成功评分不调用模型；按固定参考路径驱动浏览器，以隔离浏览器方案的正确率、耗时和资源成本。
  • 失败诊断：规则引擎自动提取失败方法、步骤、选择器和错误类型，不使用模型。
  • Codex：只开发、运行和检查工具，并在评测前用 BrowserTool 复核标注；不参与正式运行、打分或统计。

执行流程

  1. 分别启动并预热两个浏览器，浏览器进程和上下文在整轮评测中保持运行。
  2. 任务前清 Cookie、权限、HTTP 缓存、Cache Storage、Service Worker、IndexedDB、来源存储和历史，并创建新页面。
  3. 计时外静置 1000 ms，按任务交替两个 Provider 的执行顺序。
  4. 执行完整任务并采样；失败复核归入同一任务详情。
  5. 资源基线只比较双方都成功的同任务，失败与复核样本不混入正常路径。

统计口径

  • P50 与中位数是同一个统计量；总体跨任务报告 P50、平均值和 nearest-rank P95。
  • 绝对值表分别汇总两个 Provider，不展示边际分位数相除。
  • 比值表先对每个双方成功的同任务计算 Moli / Chromium，再汇总逐任务比值的 P50、P95 与平均值。
  • 每个任务仅有一个正式样本，因此逐任务不计算分位数；当前跨任务点不足以证明普遍性能优势。
  • 内存平均值是时间加权均值；任务内存 P95 来自单次任务时序采样。
  • RX = Receive（接收），TX = Transmit（发送）；总量含页面资源与 CDP，速率来自相邻采样点差分。
