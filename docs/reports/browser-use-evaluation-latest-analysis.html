为什么本轮 Moli 看起来更快

当前结果与早期公网报告不能直接比较：本轮使用本地固定测试页面，两个浏览器进程均在预热后复用，任务之间清理浏览状态；同时使用较短的确定性调用链，并修正了早期执行器与 CowAgent get_text 不一致的问题。更重要的是，资源表只保留双方成功任务：Moli 未通过的 4 个动态控件任务被排除，形成成功样本选择偏差。

因此应表述为“在本轮 11 个双方成功任务中，Moli 的同任务耗时比值 P50、平均值、P95 如上”，不能表述为“Moli 对全部任务普遍更快”。每个任务只有一个首次执行样本，也不足以建立稳定的性能置信区间。
