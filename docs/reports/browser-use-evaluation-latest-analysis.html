决策依据

  1. 默认 provider 选择成功率达到门槛且失败模式可控者，而不是只看最快一次或最低峰值。
  2. 生产密度优先看时间加权平均内存、任务内存 P95、CPU 与 MiB·s，峰值只是补充。
  3. 网络总量回答“传了多少”，平均/P95 速率回答“传输压力”；两者都含 CDP。
  4. 本轮没有模型规划，不能回答哪个内核让 CowAgent 少思考、少重试或少用 LLM token。
