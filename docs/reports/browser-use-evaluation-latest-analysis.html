本轮结论

  • 功能：Chromium 最终 100.00%（15/15），首次失败后恢复 0 项；Moli 最终 73.33%（11/15），恢复 0 项。
  • 内存：Moli 时间加权平均内存 P50 为 Chromium 的 0.16×，即低约 84.11%；任务内存 P95 和峰值仍需结合结果页解释。
  • 计算与时延：Moli CPU 时间 P50 为 0.48×、P95 为 1.19×；耗时 P50 为 0.32×、P95 为 0.64×。
  • 网络：Moli RX P50 为 3.12×、TX P50 为 2.69×。网页流量与 CDP 流量仍需进一步拆分。

产品决策边界

  1. 默认 provider 应先看首次成功率，再看重试恢复、时延和成本；最终成功率不能掩盖首次不稳定。
  2. 资源结论只来自双方首次成功交集，不能外推成所有网站上的固定倍数。
  3. 生产密度应同时看时间加权平均内存、任务内存 P95、CPU、MiB·s、网络与成功率。
  4. 本轮工具层没有模型规划；CowAgent + LiteLLM smoke 只验证端到端链路。
