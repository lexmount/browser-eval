逐项任务说明

1. 读取 Example Domain 标题

验证最短路径的页面打开与文本提取。

1–5 步2 个浏览器操作example.com
查看详细操作与通过标准

执行步骤

  1. 打开 https://example.com/
  2. 提取 h1，保存为 heading

通过标准

  • heading 必须包含“Example Domain”

2. 读取 Hacker News 首条新闻

验证动态列表等待与首项文本提取。

1–5 步3 个浏览器操作news.ycombinator.com
查看详细操作与通过标准

执行步骤

  1. 打开 https://news.ycombinator.com/
  2. 等待元素 .athing .titleline > a 可用
  3. 提取 .athing .titleline > a，保存为 title

通过标准

  • title 至少 5 个字符

3. 读取 PyPI requests 当前版本

验证包索引页加载、等待与标题提取。

1–5 步3 个浏览器操作pypi.org
查看详细操作与通过标准

执行步骤

  1. 打开 https://pypi.org/project/requests/
  2. 等待元素 h1 可用
  3. 提取 h1，保存为 package

通过标准

  • package 必须包含“requests”

4. 读取 Transformer 论文摘要

验证论文页长文本提取与内容断言。

1–5 步3 个浏览器操作arxiv.org
查看详细操作与通过标准

执行步骤

  1. 打开 https://arxiv.org/abs/1706.03762
  2. 等待元素 blockquote.abstract 可用
  3. 提取 blockquote.abstract，保存为 abstract

通过标准

  • abstract 必须包含“Transformer”
  • abstract 至少 300 个字符

5. 浏览 Python 维基条目

验证长页提取、滚动与视口快照。

6–10 步6 个浏览器操作en.wikipedia.org
查看详细操作与通过标准

执行步骤

  1. 打开 https://en.wikipedia.org/wiki/Python_(programming_language)
  2. 等待元素 h1 可用
  3. 提取 h1，保存为 heading
  4. 提取 #mw-content-text，保存为 article
  5. 向下滚动 900 像素
  6. 保存当前视口文本快照为 viewport

通过标准

  • heading 必须包含“Python”
  • article 必须包含“programming language”

6. 浏览 Moli GitHub README

验证动态代码托管页、长文本与滚动。

6–10 步6 个浏览器操作github.com
查看详细操作与通过标准

执行步骤

  1. 打开 https://github.com/lexmount/moli
  2. 等待元素 article.markdown-body 可用
  3. 提取 article.markdown-body h1，保存为 heading
  4. 提取 article.markdown-body，保存为 readme
  5. 向下滚动 1200 像素
  6. 保存当前视口文本快照为 scrolled

通过标准

  • heading 必须包含“Moli”
  • readme 至少 500 个字符

7. 从 MDN Fetch API 进入 Using Fetch

验证站内点击跳转和前后页面内容提取。

6–10 步8 个浏览器操作developer.mozilla.org
查看详细操作与通过标准

执行步骤

  1. 打开 https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API
  2. 等待元素 h1 可用
  3. 提取 h1，保存为 api_heading
  4. 提取 main，保存为 api_body
  5. 点击 main a[href*='/Using_Fetch']
  6. 等待元素 h1 可用
  7. 提取 h1，保存为 guide_heading
  8. 提取 main，保存为 guide_body

通过标准

  • api_heading 必须包含“Fetch API”
  • guide_heading 必须包含“Using”

8. 浏览 Python 教程与历史记录

验证多步骤点击、后退、前进与页面恢复。

11–15 步11 个浏览器操作docs.python.org
查看详细操作与通过标准

执行步骤

  1. 打开 https://docs.python.org/3/tutorial/index.html
  2. 等待元素 h1 可用
  3. 提取 h1，保存为 tutorial_heading
  4. 点击 li.toctree-l1 a[href='appetite.html']
  5. 等待元素 h1 可用
  6. 提取 h1，保存为 chapter_heading
  7. 提取 div.body[role='main']，保存为 chapter_body
  8. 浏览器后退
  9. 等待元素 h1 可用
  10. 浏览器前进
  11. 提取 h1，保存为 forward_heading

通过标准

  • tutorial_heading 必须包含“Python Tutorial”
  • chapter_body 至少 500 个字符

9. 浏览 RFC 9110 并进入指定章节

验证超长标准文档、锚点点击、滚动和历史恢复。

11–15 步13 个浏览器操作www.rfc-editor.org
查看详细操作与通过标准

执行步骤

  1. 打开 https://www.rfc-editor.org/rfc/rfc9110.html
  2. 等待元素 h1 可用
  3. 提取 h1，保存为 title
  4. 提取 body，保存为 overview
  5. 点击 a.section-name.selfRef[href='#name-introduction']
  6. 等待元素 #section-1 可用
  7. 提取 #section-1，保存为 introduction
  8. 向下滚动 1000 像素
  9. 保存当前视口文本快照为 scrolled
  10. 浏览器后退
  11. 等待元素 h1 可用
  12. 浏览器前进
  13. 提取 #section-1，保存为 restored

通过标准

  • title 必须包含“RFC 9110”
  • introduction 至少 300 个字符

10. 跨四个公开来源收集 Python 信息

验证多站点连续导航和长链路稳定性。

16–20 步16 个浏览器操作docs.python.org、en.wikipedia.org、github.com、pypi.org
查看详细操作与通过标准

执行步骤

  1. 打开 https://en.wikipedia.org/wiki/Python_(programming_language)
  2. 等待元素 h1 可用
  3. 提取 h1，保存为 wiki_heading
  4. 提取 #mw-content-text，保存为 wiki_body
  5. 打开 https://pypi.org/project/requests/
  6. 等待元素 h1 可用
  7. 提取 h1，保存为 pypi_heading
  8. 打开 https://docs.python.org/3/tutorial/index.html
  9. 等待元素 h1 可用
  10. 提取 h1，保存为 docs_heading
  11. 提取 body，保存为 docs_body
  12. 打开 https://github.com/python/cpython
  13. 等待元素 article.markdown-body 可用
  14. 提取 h1，保存为 github_heading
  15. 提取 article.markdown-body，保存为 github_readme
  16. 保存当前视口文本快照为 final_page

通过标准

  • wiki_heading 必须包含“Python”
  • pypi_heading 必须包含“requests”
  • docs_heading 必须包含“Python Tutorial”
  • github_readme 至少 500 个字符
