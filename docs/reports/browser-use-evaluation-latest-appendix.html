复现步骤

  1. 准备 Docker Engine、Python 3.11+、至少 4 CPU/6 GiB 内存。
  2. 运行 ./examples/browser_use/run.sh；每个任务在每个 Provider 上首次执行 1 次。
  3. 改变失败重试次数：BROWSER_USE_EVAL_FAILURE_RETRIES=1 ./examples/browser_use/run.sh。
  4. 检查 attempts.jsonl、manifest.json、summary.json 与分页 HTML。

限制

  • 固定测试页面提高可重复性，但不能代替真实公开网站兼容性评测；两类测试应分开报告。
  • 每任务只有一个首次样本，逐任务不报告分位数；总体分位数是跨任务分布。
  • 双方成功任务会排除任一 Provider 失败的任务，资源对比存在选择偏差，必须与正确率一起阅读。
  • 采样间隔 100 ms，短尖峰可能遗漏。
  • 浏览器进程保持运行且任务间清理状态，但分配器保留内存不等于缓存污染。
  • 这是工具调用层，不是 CowAgent + LiteLLM 的 Agent 规划质量评测。
