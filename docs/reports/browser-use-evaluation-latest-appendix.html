复现步骤

  1. 准备 Docker Engine、Python 3.11+、至少 4 CPU/6 GiB 内存。
  2. 运行 ./examples/browser_use/run.sh；脚本执行完整基准，并依次生成原始记录、汇总数据和分页 HTML。
  3. 如需为失败任务补充一次同任务证据，设置 BROWSER_USE_EVAL_FAILURE_RETRIES=1；该记录不会另计为新任务。
  4. 如只需从已有 attempts.jsonl 重算全部指标和报告，运行 uv run python examples/browser_use/rebuild_report.py。
  5. 检查 attempts.jsonl、manifest.json、summary.json 与分页 HTML；所有比值、分位数和均值均由仓库脚本计算，Codex 不参与统计。

复现限制

  • 全部任务来自公网，页面内容、网络状态或站点策略变化可能导致数据集漂移；运行前需复核数据集 SHA 与标注证据。
  • 采样间隔 100 ms，持续时间短于采样间隔的尖峰可能遗漏。
  • 浏览器进程保持运行且任务间清理状态；分配器保留内存不等于缓存污染。
