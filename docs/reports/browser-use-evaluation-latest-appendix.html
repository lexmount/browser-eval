复现步骤

  1. 准备 Docker Engine、Python 3.11+、至少 4 CPU/6 GiB 内存及公网。
  2. 运行 ./examples/browser_use/run.sh；默认每任务 3 次。
  3. 改变重复次数：BROWSER_USE_EVAL_REPEATS=3 ./examples/browser_use/run.sh。
  4. 检查 attempts.jsonl、manifest.json、summary.json 与分页 HTML。

数据字段

数据结构
对象关键字段用途
attempttrace / error / duration_ms未截断错误与逐工具调用证据
resourcememory mean/p95/peak/retained/MiB·s内存水平、尾部、峰值、保留量和积分
resourceCPU total/average/p95/peakCPU 总量与时序压力
resourcenetwork total/average/p95/peak网络总量与速率压力
summaryfunctional / paired intersection功能全样本与成功交集分离

限制

  • 公网会波动；交替与重复不能完全消除外部变化。
  • 每任务 3 次，任务级 P95 等于最大值。
  • 采样间隔 100 ms，短尖峰可能遗漏。
  • 浏览器不关闭且状态清理，但分配器保留内存不等于缓存污染。
  • 这是工具调用层，不是 CowAgent + LiteLLM 端到端层。
