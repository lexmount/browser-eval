关键技术结论

  • 速度与资源：双方成功任务的逐任务 Moli / Chromium 比值中，耗时比平均值为 1.88×，时间加权平均内存比平均值为 0.45×，网络接收量比平均值为 2.18×。
  • 时序边界：Moli 的 1 Hz 是 CDP screencast 下采样，不等于 JavaScript 或 requestAnimationFrame 只有 1 fps；源码中的 rAF 目标间隔为 16 ms。
  • 根因边界：布局与 actionability 证据只能定位现象，尚不能确认 screencast、渲染器或适配层中的具体根因。查看逐任务证据与验证方案。
