如何解读

  • 成功率使用全部尝试；耗时、内存、CPU、RX/TX 只使用双方均成功配对样本，避免失败提前结束造成资源假低。
  • 比值小于 1 表示 Moli 数值更低；网络量低不自动等于更好，需要结合页面完整性与成功率。
  • 本轮支持把 Moli 定位为内存优先推荐项；CPU、尾时延和成功率对齐 Chromium 前，不建议设为默认值。
  • 完整任务调用、原始异常、逐调用轨迹和规则化诊断均在“结果与诊断”页。
