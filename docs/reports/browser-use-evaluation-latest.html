结论摘要

结论与产品建议

本轮建议默认使用 Chromium：它通过了全部任务；Moli 在双方均成功的任务上耗时和内存更低，但仍有 4 个任务未通过，可作为重视资源成本且任务已验证兼容时的推荐选项，暂不宜设为默认值。

这是浏览器工具调用层的确定性微基准，不是 LLM Agent 排名。15 个任务的结果答案唯一，评测程序重放一条预先声明的有效参考路径；结果由程序逐字判定，LLM 不参与成功评分。每个任务先执行 1 次，仅结果失败时最多重试。

如何解读

  • 结果正确率是主指标；“结果与过程均正确率”单独报告，不与结果正确率混成一个数。
  • 耗时、内存、CPU、RX/TX 只比较双方首次结果均正确的同任务，重试与失败样本不进入资源基线。
  • 配对比值先对每个同任务计算 Moli / Chromium，再报告这 11 个比值的 P50、平均值、P95；小于 1 表示 Moli 数值更低。
  • 本轮只有 11 个成功配对点，且 Moli 失败的 4 个任务被排除，速度结论存在成功样本选择偏差，不能外推为全任务更快。
  • 完整标准答案、实际输出、原始异常和逐调用执行轨迹均可审计。
